# 基础组件源码

本目录的组件源码取自 shadcn-vue `2.8.2` CLI 的 `reka-nova` registry，来源快照日期为 2026-09-07。上游文件摘要记录在 `upstream.json`，许可证见 `LICENSE.shadcn-vue`。

这些文件是项目维护的源码。更新上游时先在隔离目录生成并比较，不直接覆盖本目录。CLI 版本不代表远端 registry 内容不可变，因此同时保留来源摘要。

组件约定：

- 类名合并使用 `@/lib/ui`，视觉变量映射到项目 token。
- 状态变体使用 Reka 的 `data-state` 属性。
- 动画由产品组件和统一配置决定。
- 字体使用项目自托管资源，全局样式由 `src/styles/` 维护。

业务页面通过 `components/` 中的产品封装使用交互复杂的浮层、选择器和反馈组件；本目录只承担可组合的基础结构与状态。
