# v0.5 Changelog

RayleaBot v0.5 归纳 v0.4 归档之后到 2026-09-11 的全部提交（`c090715f`..`2c8ed50e`，共 265 个），作为历史基线归档。前置基线见 [v0.4.md](./v0.4.md)。本轮候选说明见 [0.5.0 候选说明](../release/notes/v0.5.0.md)，验收记录见 [候选验收记录](../release/validation-v0.5.0.md)。

## 主线交付

- 聊天连接按适配器实例管理：配置 `schema_version` 4 用命名的 `adapters` 列表取代 `onebot` 与 `qq_official` 单例，同协议可运行多个实例；身份、凭据、事件、出站路由、黑白名单作用域与入站路径均按实例隔离。QQ 官方机器人成为第二个正式适配器。
- 插件协议 v3：`init.bots` 与 `bot.identities.changed` 提供多适配器身份快照，`init.timezone` 传递宿主生效时区；协议 v2 SDK 不能与 v3 宿主握手，插件须用当前 SDK 重新构建。
- 全新分发：默认值内嵌在服务端，`user.yaml` 只保存用户配置；SQLite 从当前结构 `000001` 初始化；备份 manifest v3 只恢复当前格式。不再保留旧配置、旧运行数据与旧插件合同的兼容路径，本轮末尾删除了退役配置键诊断与空 `scheduler.timezone` 回退。
- 管理面迁移到 Reka UI 并删除旧 UI 栈：配置工作台重构、协议中心按适配器展示、管理员凭据修改、集合分页与刷新协调、请求与下载取消统一、诊断按错误码展示恢复操作。
- 契约驱动的生成物：错误码与诊断目录、协议 wire 模型、发布 artifact 标识、Launcher API 子集均从 `contracts/` 生成；资源清单 deps v5 在 Server、Launcher 与发布脚本间共享校验；`web-api.openapi.yaml` 的 `info.version` 定义为契约修订并进入严格校验。
- 服务端按职责重组并清理：共享契约、文件与平台包归入 `platform/`，插件 wire 类型归入 `plugins/pluginwire`；路径限制与有界流集中到 `fs`；安装阶段、恢复计划与文件事务分离；仓储查询迁移到 sqlc；末尾以 31 个提交删除生产与测试均不可达或仅测试调用的代码。

## Contract / Schema 冻结

| 表面 | 目标版本 |
| --- | ---: |
| `config.user.schema.json` `schema_version` | 4 |
| `plugin-info.schema.json` | 3 |
| `plugin-protocol.schema.json` | 3 |
| `plugin-artifact.schema.json` | 2 |
| `plugin-management-ui.yaml` / bridge | 3 |
| `backup-manifest.schema.json` | 3 |
| `deps-manifest.schema.json` | 5 |
| `release-manifest.schema.json` | 2（`plugin_protocol_version` 固定为 `"3"`） |
| `cli-commands.yaml` | 2 |
| `web-api.openapi.yaml` `info.version` | 0.2.0 |
| SQLite 当前结构 | `000001` |

- `adapters` 以 `x-collection-key: id` 寻址实例，秘密引用与应用效果 diff 按实例标识而不是列表位置解析；`qq_official.enabled` 上移到实例。
- 入站路径改为 `/api/adapters/{id}/reverse-ws` 与 `/api/adapters/{id}/webhook`，各自用所属实例的令牌认证；`GET /api/adapters` 返回已配置实例与可添加的协议。
- `scheduler.timezone` 要求非空 IANA 标识；缺省键由 schema 默认值补齐，空值被拒绝。
- `error-codes.yaml` 是 Server 与 Web 错误码、诊断身份的唯一来源；带 `x-error-code-registry` 的响应字段在 fixtures 与 HTTP 样例中必须使用已登记的错误码。
- 会话词汇与身份作用域在契约中命名；治理条目写操作要求显式 `scope`（OneBot 全局或完整实例 / bot 身份），旧的无作用域请求被拒绝。
- 旧格式合同只作为精确拒绝的负向样例保留。

## 适配器与聊天管线

- QQ 官方机器人：应用访问令牌来源、网关连接与重连、事件规范化与投递、图片 / 视频 / 语音发送与回复、群成员与推送权限事件、发送失败正式错误码、配置热更新、身份上报与状态发布、投递凭据与网关生命周期状态保留。
- 中立聊天事件与出站包：适配器共享事件转换、重连退避、协议中立的发送结果与失败；出站按适配器实例而非协议路由，目标名称由所属适配器解析；插件可为主动推送指定适配器。
- 治理与准入：黑白名单、配额与熔断按协议、适配器与 bot 身份作用域；权限存储不可用时拒绝准入；QQ 事件执行权限检查且不共享入站写入；每次出站准入绑定一个身份快照。
- OneBot：动作与元数据按实例路由，实例开关生效，会话身份在单处推导；协议中心卡片展示已连接账号资料。

## 插件协议与 SDK

- 协议 v3 身份快照与宿主时区；Go SDK 通过 `EventContext.Bots` 提供隔离的完整列表，`EventContext.Bot` 按聊天事件来源选择身份，平台内部事件仅在单身份时提供便利值。
- 插件生命周期操作按插件串行协调并保留运行时所有权；安装与卸载事务失败向上传播；设置写入与密钥事务统一；命令模式在配置刷新后保留；插件身份统一并跟踪安装结果；退出对账前先消费最终协议帧。
- 插件执行与进程运行时分离，聊天与执行值不再混入进程运行时；宿主装配时校验必需服务依赖。
- Go SDK：开发时复用插件构建输出；`pluginbuild` 只保留 `Build`、`Pack` 与 `Inspect` 库入口，删除解析命令行的 `Main`；Vue SDK 限定声明输出范围。
- 开发工具：构建缓存与工作区变更对账、开发插件无需重启同步、开发启动脚本显示 Launcher 窗口、离线可用的固定 Wails 工具缓存。

## 配置、数据与恢复

- 配置：嵌入默认值与单一用户文件；保存结果区分已持久化、立即生效与需重启；保存修订保留并补偿失败写入；热更新在类型化配置上按路径保留未应用字段；秘密路径按文档解析；秘密恢复不再补造省略的段。
- 时区统一：调度、服务日志、管理面时间展示与插件 `init.timezone` 使用同一生效时区，保存的时区变更在重启前不生效。
- 存储与恢复：单一当前 schema；恢复兼容性由归档 schema 版本推导；恢复 preflight 有界、文件替换事务化；跳过的插件持久化为 disabled，写入失败即报错并保留待检查摘要。
- 渲染：只保留命名的当前模板，删除编辑器、回滚与修订持久化；模板缓存统一并关闭自有资源；前台激活与截图协调、按目标等待资源、遵守调用方超时、保留 Edge 进程所有权、Windows 卷路径修正。

## 管理面与 Launcher

- Web：shell、认证、协议中心、插件工作区、治理控件、诊断工作台迁移到 Reka UI；浮动标签表单、紧凑反馈取代横幅、集中式协议连接对话框、内嵌焦点指示；侧栏账号管理与构建版本；隔离插件页在生产构建中恢复；可访问控件与就绪反馈；液态玻璃认证入口与无损 WebP 背景；剩余硬编码文案迁入 locale。
- Web 数据流：管理集合分页、刷新生命周期协调、请求与下载取消统一、可信插件安装错误映射、日志控件与配置草稿共享、无消费者组件与 vendored 基础组件删除。
- Launcher：类型化 API 边界与可观察的关闭失败、桌面模型与枚举来自 Wails 绑定、启动与进程协调分离、窗口布局与环境反馈加固、GTK3 标签构建 Wails CLI、账号凭据 API 类型同步。

## 平台与运行时

- 文件与 HTTP：路径限制、有界流与流式摘要集中；管理 JSON 请求体有界并校验；错误响应来自规范目录；领域失败按身份分类并保留底层原因；`DomainError` 只承载错误码与详情。
- 日志与诊断：操作模板与结构化上下文分离、凭据脱敏、操作者消息简化并减少重复；诊断在 CLI 与在线导出间共享健康检查；状态快照显式携带运行时资源。
- 生命周期：关闭受监督并释放部分构建的资源；已接受任务、插件进程与浏览器在关闭时继续回收；删除 nil 上下文与 nil 接收者的静默回退，装配缺陷直接暴露。
- 依赖资源：下载有界、归档提取受限并绑定打包字节的哈希；FFmpeg 固定为 9.0.1 月度构建；服务缺失时拒绝启动并共享凭据与 HTTP 默认值。

## 发布与门禁

- 发布：中文版本说明经校验后发布；artifact 标识由 manifest 枚举生成；依赖清单哈希绑定打包字节；签名配置错误直接失败，归档内容规则共享；artifact 布局共享并演练当前格式恢复；定义随包 Windows 主程序的发布者固定规则；候选版本与插件核心版本要求对齐；Windows 提取根移动加锁重试、恢复服务在关闭失败后回收、macOS Bash 打包参数保留。
- CI：Windows 源码 lint 与插件进程测试；原生 artifact 验证可复用且不发布；生成 API 与候选分支跨消费者校验；Launcher 图标漂移检查；适配器与快照关闭竞态测试；检查器输入与核心回归覆盖；`.gitattributes` 变更分类；原生浏览器测试与插件进程测试隔离；仓库统计图改为推送到 `main` 时生成。
- 2026-09-11 全量验证：Server `go vet` 与 `go test ./...` 通过；Web typecheck、81 个单测文件 465 项测试与 production build 通过；Launcher 16 个测试文件 65 项测试与 Go 测试通过；Go SDK 全量测试与 `raylea-plugin` 构建通过；脚本 77 项 node 测试、契约 strict 校验、错误码与运行时 schema 生成物校验、137 个 Markdown 文件链接检查、第三方 notices 检查通过；deadcode 在 `-test` 模式下 Server 与 Launcher 均为空。
- Windows 实包原生 UI、插件与 PNG 功能流程及托管检查结果见 [候选验收记录](../release/validation-v0.5.0.md)。
