# 日志与发送结果

默认日志保留逐条消息收发、重要状态变化和真实失败。无变化的后台轮询使用 DEBUG；同类后台故障记录首条，每五分钟汇总次数，确认恢复后记录恢复。日志聚合不改变调度结果统计。

RayleaBot 生成的日志时间、管理日志存储及 HTTP / WebSocket 日志摘要统一使用 UTC，格式为带 `Z` 和九位小数秒的 RFC3339，例如 `2026-09-22T15:17:11.924081800Z`。旧日志中的时区偏移和不同小数精度仍按同一绝对时刻读取。日志生成时间与来源事件时间分别保留；Web 按当前生效的配置时区展示时间，将日期筛选范围转换为 UTC 查询。

日志正文面向日常运维，说明对象、结果和必要的处理办法。例如“插件订阅与解析已启动”“连接已断开，正在重连”。收到消息直接显示消息摘要，不附加内部排队过程；插件目录、任务 ID、耗时、协议错误码等诊断信息放在结构化详情中。备份位置、配置错误所在文件等有助于操作的路径仍可显示在正文。

插件扫描明细、启动进度、缓存命中和请求诊断使用 DEBUG；默认级别保留启动结果和配置状态变化。一次操作的进度与结果不重复记录为 INFO。重复的后台故障由汇总日志报告，来源请求的逐次诊断使用 DEBUG；恢复与检查结果合并记录。插件业务结果与调度统计由执行流程记录，历史日志保留事件发生时的记录。

插件扫描的数量摘要也使用 DEBUG，扫描失败与无效插件仍报告告警。图片模板按一次系统或插件同步汇总实际更新数量；未变化时不记录更新，单个模板的 ID 与摘要保留在 DEBUG 中。

异步任务通过管理日志呈现等待、执行和完成状态。正文直接说明操作与对象，例如“安装插件‘三角洲助手’（执行中）”；任务类型代码与安装来源路径放在详情中，不重复拼接“任务执行中 plugin.install”等前缀。任务进度数值变化不重复写日志。

插件在内部请求未完成时关闭通信或退出，由 Runtime 记录一次带插件 ID 和错误码的 WARN；退出码为 0 也不能代表请求已经完成。分发和调度层在收到 Runtime 已记录故障的标记后省略重复告警。

“内部事件未完成”表示 Server 与插件的事件处理未完成，不能据此认定 QQ 消息发送失败。发送请求发出后未取得确定回执时使用 `adapter.send_unconfirmed`，消息可能仍会送达；系统不自动重发。

停用插件会等待当前初始化或重载操作结束，再使用 5 秒停止预算。Server 关闭时取消已接收的投递，在关闭期限内停止插件进程，然后等待任务结果写入完成；尚未开始的定时事件按取消计入 `other`。

开发日志按职责分别保存在 `logs/dev/server/`、`logs/dev/web/`、`logs/dev/launcher/` 和 `logs/dev/build/`。`logs/dev/start/` 保存进程编排、构建结果与子日志位置。开发日志和 Launcher 托管的 `logs/server/`、`logs/launcher/` 使用写入时的 UTC 日期命名为 `YYYY-MM-DD.log`，跨 UTC 零点后的首次输出自动切换文件；没有输出的日期不创建空文件。文件日期不随系统或 Web 时区变化，历史文件不重新拆分。第三方进程的来源时间不自动改写；开发日志去除颜色与终端控制字符，并保留脱敏后的诊断内容。插件 stderr 按完整行脱敏；超长诊断行会被省略。

开发终端的抬头显示启动模式、Node 版本与 Server / 插件源码监听方式。启动区集中显示当前阶段、子任务、插件进度和阶段结果，完成行保留耗时，复用等编排说明归入对应阶段。启动摘要集中显示管理面地址、日志目录和退出方式。配色使用终端调色板中的青绿强调与告警色，背景沿用终端主题，`NO_COLOR` 关闭配色；重定向、CI 与不支持控制序列的终端使用静态行。

子进程日志始终即时写入文件。启动期间的普通输出暂存到有容量上限的终端队列，摘要完成后在“进程日志”区域按接收顺序显示，并保留来源时间；后续日志直接追加。队列超限时省略较早或过长的普通输出并提示数量，文件记录仍完整。告警和 stderr 诊断即时显示在启动区；启动尚未完成便退出或失败时，也会释放暂存输出，不会显示成功摘要。

构建资源清单与普通工具输出写入构建日志，告警和错误仍显示，命令失败时补充最近未显示的输出及完整日志位置。进程日志对齐时间、来源和正文，窄窗口中将来源与正文分行，长诊断按中文与 emoji 的完整字符换行；Launcher 的构建与平台信息显示 Wails、Go、系统和 WebView2 版本。结构化详情保存在对应文件中，动画不会写入日志；窗口缩放与阶段切换会清理此前的进度显示。

关闭开发流程后停止派生新的构建与同步子进程，并等待同一次清理完成。主动终止的构建显示“已取消”，不作为启动失败重复报告。

首次设置地址只向需要初始化的交互终端显示，管道与日志文件不能接收 setup 凭据。管理日志与诊断详情不能包含 token、Cookie 或密码。
