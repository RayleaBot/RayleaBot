# Docs Agent Guide

文本编辑使用 `.agents/skills/editing-final-state-content/SKILL.md`。

## Documentation

- 文档按所属正式来源说明能力、限制、架构与操作，不定义另一套对外接口；只记录已提供的使用方式，不把尚未发布的能力写成可用功能。
- 保留读者需要的设计理由、前置条件、数据流、依赖顺序和步骤，删除无关编辑过程叙述。
- 契约或正式行为变化影响文档时，同轮更新受影响的现行说明；只修改确有漂移的内容。
- 执行计划放在 `docs/plans/`，描述拟实施的设计并只约束对应任务；计划落地并写入现行文档后删除，没有执行计划时以契约与现行文档为准。
- `docs/CHANGELOGS/` 下已归档的版本记录不修改，除非用户明确要求。
- 使用大小写正确的仓库相对链接；中文文件通过 README 或所属目录索引提供入口。
