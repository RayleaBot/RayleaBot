RayleaBot 0.4.0-beta.1 是 0.4.0 的预发布版本，用于安装、初始化和兼容性验收。发布工作流将其标记为 prerelease，清单通道为 beta，不替换稳定版 latest。

## 主要变化

聊天连接按适配器实例管理并新增 QQ 官方机器人；插件改为原生程序，支持多轮对话、消息优先级与阻断、后台事件与服务调用和 KV 期限；管理面与启动器重新设计，桌面完整包支持一键更新。插件使用 manifest v4、JSONL protocol v4 与 artifact v2。完整能力和接口变化见[同一标签中的 0.4.0 说明](https://github.com/RayleaBot/RayleaBot/blob/v0.4.0-beta.1/docs/release/notes/v0.4.0.md)。

## 安装与兼容性

从本 Release 的 Assets 选择对应平台的运行包，解压到新的目录后初始化。GitHub 自动生成的 Source code 归档不是运行包。

0.3.x 与 0.4.0 不兼容，需要在新目录全新安装并初始化。旧更新器依赖已移除的签名资产，无法自动升级；旧备份、配置与插件包不受本版支持，不提供旧格式迁移。新安装默认监听 `0.0.0.0:8080`，局域网设备可以直接访问。详见[0.3.x 兼容性说明](https://github.com/RayleaBot/RayleaBot/blob/v0.4.0-beta.1/docs/release/notes/v0.4.0.md#03x-兼容性)。

现行 manifest v4 契约要求插件声明最低核心版本为 `0.4.0` 或更高，`0.4.0-beta.1` 低于该下限，因此本预发布不能安装 v4 插件。完整插件流程需使用满足该下限的核心版本与兼容插件包；本版先用于核心安装与初始化验收。

## 平台与验收边界

- Windows x64 与 Linux x64 提供完整包，Linux x64 另提供服务端包。
- macOS arm64 标为 experimental，验收范围先限安装与初始化；没有 Developer ID 签名、公证与 Gatekeeper 实机通过承诺。
- 发布门禁确认同一提交的 nightly 和打包 smoke；真实协议、公开插件目录及公开下载包的验证结果仍以[实包验收登记](https://github.com/RayleaBot/RayleaBot/blob/v0.4.0-beta.1/docs/engineering/manual-smoke.md#公开发行物)为准，未执行的项目不视为通过。
