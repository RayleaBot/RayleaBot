RayleaBot 0.4.0 的测试版，供想提前体验新版本的用户试用。这是 0.3.1 之后的首个新版本：可以同时接入多个聊天账号并支持 QQ 官方机器人，插件改为原生程序，管理面与启动器全面重新设计。正式版发布前仍可能调整，请不要用在重要环境中。

> [!IMPORTANT]
> 0.4.0 与 0.3.x 不兼容：配置、备份和插件都不能沿用，也不能覆盖升级，请解压到新的目录全新安装。0.3.x 不会提示更新到测试版。

## 本次重点

- **多个聊天连接与 QQ 官方机器人**：可以同时接入多个 OneBot11 账号（如 NapCat），也可以只用 QQ 官方机器人；身份、发送和黑白名单按连接分开管理。
- **全新的管理面与启动器**：保存配置时会说明已生效还是需要重启，诊断按错误给出处理办法，状态页显示各连接的收发消息趋势。桌面版可以在启动器里一键更新。
- **插件能做更多事**：插件可以发起多轮对话，回复时不必重复命令前缀；扫码登录等较慢的流程可以在后台进行；插件之间可以互相调用。帮助菜单按插件列出实际可用的命令。
- **运行更稳**：一个群刷屏不会拖慢其他群；停止服务时会先回复完已收到的消息；FFmpeg 等组件改为在管理面按需准备，不再拖慢首次启动。

## 测试版的限制

- **暂时不能安装插件**：新版插件要求核心版本至少为 0.4.0 正式版，测试版无法安装插件商店或本地的插件。本版适合先体验安装、接入聊天账号和管理面。
- **macOS 为实验性支持**：安装包没有 Apple 签名与公证，系统阻止打开时按[部署指南](https://github.com/RayleaBot/RayleaBot/blob/v0.4.0-beta.1/docs/user/deployment.md#首次安装)放行。

## 下载与安装

| 使用环境 | 下载 |
| --- | --- |
| Windows x64 桌面完整包 | [ZIP](https://github.com/RayleaBot/RayleaBot/releases/download/v0.4.0-beta.1/RayleaBot-v0.4.0-beta.1-windows-x64-full.zip) |
| Linux x64 桌面完整包 | [tar.gz](https://github.com/RayleaBot/RayleaBot/releases/download/v0.4.0-beta.1/RayleaBot-v0.4.0-beta.1-linux-x64-full.tar.gz) |
| macOS Apple Silicon 桌面完整包（实验性） | [tar.gz](https://github.com/RayleaBot/RayleaBot/releases/download/v0.4.0-beta.1/RayleaBot-v0.4.0-beta.1-macos-arm64-full.tar.gz) |
| Linux x64 服务端包 | [tar.gz](https://github.com/RayleaBot/RayleaBot/releases/download/v0.4.0-beta.1/RayleaBot-v0.4.0-beta.1-linux-x64-server.tar.gz) |

解压到新的目录后，桌面完整包运行 `RayleaLauncher`，服务端包运行 `raylea-server`，按提示创建管理员。首次使用请阅读[部署指南](https://github.com/RayleaBot/RayleaBot/blob/v0.4.0-beta.1/docs/user/deployment.md)。下方 Assets 中的 Source code 是源码归档，不能直接运行。

新安装默认监听 `0.0.0.0:8080`，同一局域网的设备可以直接打开管理面。只在本机使用时把 `server.host` 改为 `127.0.0.1`；开放到局域网时，请为聊天连接设置访问令牌，并用防火墙限制来源，见[本机与局域网访问](https://github.com/RayleaBot/RayleaBot/blob/v0.4.0-beta.1/docs/user/deployment.md#本机与局域网访问)。
