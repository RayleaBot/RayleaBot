RayleaBot 0.4.0 是 0.3.1 之后的首个功能版本：可以同时接入多个聊天账号并支持 QQ 官方机器人；插件改为可用任意语言实现的原生程序，能发起多轮对话、在后台处理较慢的流程并互相调用；管理面与启动器重新设计，桌面版支持一键更新。

> [!IMPORTANT]
> 0.3.x 与本版不兼容：配置、备份和插件都不能沿用，也不能覆盖升级，请在新的目录全新安装。0.3.x 的插件需要更新到 0.4.0 适配版本，见下文“升级说明”。

## 本次重点

- **多个聊天连接与 QQ 官方机器人**：同一协议可以接入多个账号，也可以只用 QQ 官方机器人；身份、发送和黑白名单按连接分开管理，添加、删除或修改连接保存后立即生效，不需要重启服务。QQ 官方机器人支持图片、视频、语音与文件；群管理员开启“接收全部群消息”后只处理 @ 机器人的消息，插件回复优先按被动回复发送，不占用主动推送额度。
- **原生插件与插件商店**：插件是你确认安装的本地程序，安装包自带目标平台的可执行文件，可以用任意语言实现。商店读取官方目录和你添加的 HTTPS 目录，网络不可用时使用上次成功读取的结果；插件管理页直接在管理面中打开。
- **插件能做更多事**：插件可以发起多轮对话，回复时不必重复命令前缀；扫码登录等较慢的流程可以在后台进行；插件之间可以互相调用，也可以声明自己的命令前缀和帮助样式。
- **管理面、启动器与更新**：保存配置时会说明已生效还是需要重启，诊断按错误给出处理办法，状态页显示各连接的收发消息趋势。桌面版在启动器“关于应用”中确认后一键更新；服务端包先执行 `raylea-server update download` 准备更新，再停服执行 `raylea-server update apply`。

## 新增与改进

- **命令与帮助**：命令只按文字内容匹配，@ 等内容不再影响识别。帮助菜单按插件列出实际生效的前缀，用法写成可以直接发送的完整命令；“<插件名>帮助”由插件按自己的样式回复。
- **冷却与消息处理**：同一用户在同一个群或私聊里，一个冷却期内只收到一次冷却提示，可在限流中心关闭。每个群和私聊的消息分开处理，一个群刷屏时其他群照常响应；单个会话积压超过 16 条时丢弃新消息。
- **出图**：插件出图可以使用插件自带或下载的图片与字体，宽度可以随内容自适应；插件安装包上限提高到 1 GiB，以容纳模板素材。
- **配置与时区**：配置文件只保存你改动过的设置，默认值随程序更新；定时任务、日志显示和插件使用同一个时区。
- **运行环境**：FFmpeg / FFprobe 改为在管理面按需准备，Windows 与 Linux 下载量约减半，不再拖慢首次启动。Linux 服务端包附带 Chromium 依赖说明，`doctor` 会检查缺失的库；Windows 启动器缺少 WebView2 时提示安装。
- **更新来源**：在“配置 → 版本与更新”中可以选择稳定版或测试版通道，或指定目标版本，不会自动降级。默认同时检测 GitHub 直连与三个公共加速源并自动选择，下载失败时切换来源；加速源由第三方运营，不信任时可以删除或改为直连。离线设备可以用 `raylea-server update download --file` 导入在其他设备上下载的发布包。
- **日志与诊断**：日志按 UTC 记录，管理面按配置时区显示；收发消息日志显示机器人昵称和发送详情；米游社 Cookie、SToken 与抽卡链接中的凭据会被脱敏。管理面导出的诊断包包含运行时信息，便于定位卡死与内存问题，不含消息正文。管理日志改为后台批量写入，进程异常退出时可能丢失最后一批尚未写入的管理日志。
- **关闭与登录**：停止服务时先回复完已收到的消息再断开连接，插件停止时会回收它启动的全部子进程。登录会话改为随机令牌，数据库与备份只保存令牌的哈希，泄露的备份不能用来伪造登录。

## 移除与变化

- **更新**：不再使用发布签名、独立更新程序与更新回滚，改为经 HTTPS 检查版本后一键更新；取舍理由见[更新策略与理由](https://github.com/RayleaBot/RayleaBot/blob/v0.4.0/docs/release/delivery-and-upgrade.md#更新策略与理由)。
- **插件信任**：宿主不再限制插件的网络与文件访问，安装前请确认插件来源。本地插件包一次确认即可安装；商店插件只在首次安装或来源变化时需要确认。
- **恢复备份**：只检查备份完整性与版本，需要恢复到新解压的空目录。
- **密钥保存**：平台密钥不再额外加密，原值保存在独立存储中；配置文件只保存引用，管理面不回显。请妥善保管数据目录与备份。
- **限流**：删除按目标的出站熔断和每个插件的消息限流，按目标限流保留。
- **监控接口**：删除 Prometheus 指标接口 `/api/system/metrics`，外部探活使用 `/healthz` 与 `/readyz`。管理面不再显示 OneBot 兼容矩阵，见 [OneBot 兼容说明](https://github.com/RayleaBot/RayleaBot/blob/v0.4.0/docs/dev/onebot-compatibility.md)。
- **界面**：管理面按桌面浏览器设计，建议在 1920×1080 及以上分辨率使用，手机与平板没有专门布局。

## 升级说明

0.3.x 的更新器无法升级到本版，检查更新时会提示发布清单无效。0.3.x 的配置、备份和插件包均不受本版支持，也不提供迁移：请在新目录全新安装并初始化，再从插件商店安装 0.4.0 适配版本的插件。

新安装默认只监听本机 `127.0.0.1:8080`，与 0.3.x 相同。需要局域网访问时把 `server.host` 改为 `0.0.0.0` 或内网地址；此时 OneBot 反向 WebSocket 与 Webhook 必须设置访问令牌，未设置令牌的入站连接会被拒绝。协议中心启用这两种连接方式时会自动生成令牌，见[本机与局域网访问](https://github.com/RayleaBot/RayleaBot/blob/v0.4.0/docs/user/deployment.md#本机与局域网访问)。

## 开发者说明

插件合同改为 manifest v4、JSONL protocol v4 与 artifact v2，`min_core_version` 须不低于 `0.4.0`（不接受其预发布版本）。0.3.x 插件与按 Go SDK v0.4.0、v0.5.0 构建的插件都不能在本版运行，请用随本版发布的 Go SDK v0.6.0 重新构建；其他语言实现按[插件协议](https://github.com/RayleaBot/RayleaBot/blob/v0.4.0/docs/plugin/protocol.md)更新。

- **权限与资源**：manifest 删除 `permissions`，宿主不再代理 HTTP 请求与文件存储。插件使用自己的 HTTP 客户端，数据写入 `RAYLEABOT_PLUGIN_DATA_DIR`，可重建的缓存写入 `RAYLEABOT_PLUGIN_CACHE_DIR`。
- **多实例**：事件携带 `source_adapter` 与 `source_protocol`，主动发送需要选择实例；`init.bots` 提供各连接的身份快照，`init.timezone` 传递宿主时区。
- **新增能力**：多轮对话、消息优先级与阻断、后台事件与处理期限、服务调用、专属命令前缀与兜底命令、自带帮助命令、计划任务删除、KV 期限，以及引用插件文件与字体的出图资源。用法见[插件 SDK](https://github.com/RayleaBot/RayleaBot/blob/v0.4.0/docs/plugin/sdk/README.md)。
- **Webhook**：删除内置 token、签名与重放保护；`raw_payload` 携带请求头与原始正文，由插件按对方平台规则验签与去重。
- **管理页**：bridge 退役，`@rayleabot/plugin-ui` 以当前管理会话调用管理 API；脚本须打包进插件，外部 CDN 与内联脚本会被 CSP 拒绝。见[插件管理页](https://github.com/RayleaBot/RayleaBot/blob/v0.4.0/docs/plugin/management-ui.md)。
- **QQ 官方投递**：处理 QQ 官方消息事件期间向同一会话发送的消息按被动回复投递；`at` 转为文本标记，媒体支持 `base64://`，不支持的消息段使整条消息不发送。逐段规则见[插件协议](https://github.com/RayleaBot/RayleaBot/blob/v0.4.0/docs/plugin/protocol.md#qq-官方机器人的投递规则)。
- **构建与分发**：Go 插件使用 `raylea-plugin build-go`，其他语言先构建原生入口再使用 `raylea-plugin pack`；插件构建不再生成 SBOM。见[插件开发与分发](https://github.com/RayleaBot/RayleaBot/blob/v0.4.0/docs/plugin/store-and-development.md)。
- **管理 API**：错误信封删除 `message_key`，客户端按 `code` 处理。
- **许可与工具链**：Go SDK（含 `raylea-plugin`）与 Vue SDK 改用 MIT 许可，插件只链接 SDK 时可以自行选择许可。源码构建使用 Go `1.27.2`、Node.js `26.10.0` 与 pnpm `11.25.0`，不再需要 Python，见[工程基线](https://github.com/RayleaBot/RayleaBot/blob/v0.4.0/docs/engineering/baseline.md)。
