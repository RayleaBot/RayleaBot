RayleaBot 0.7.0 是候选版本，合并了未单独发布的 0.6 变化：多轮对话、消息优先级与阻断、KV 期限和一键更新；同时按“插件是管理员确认安装的可信本地代码”精简宿主，插件协议升至 v4。当前尚未公开分发，本文用于候选包安装与验收。

> [!IMPORTANT]
> 已安装的 manifest v3 / protocol v3 插件在本版显示为合同不受支持并保持禁用，数据目录保留。需要用当前 Go SDK 按 v4 重新构建；使用宿主 HTTP 请求、宿主文件存储、webhook 内置鉴权或管理页 bridge 的插件还须修改代码，见下文“开发者说明”。

## 本次重点

- **多轮对话**：插件可以登记下一条对话输入，用户回复无需重复命令前缀；对话按协议、适配器实例、机器人和会话目标隔离，个人等待再区分发送者，超时后可选通知插件。Go SDK 提供回调式询问。
- **消息优先级与阻断**：插件在 manifest 中声明 `priority` 与 `block`，消息按优先级分层执行，同层并发并保留跨层顺序；插件可在处理结果中决定是否继续传播。管理面只读展示声明。
- **KV 期限与一键更新**：插件私有 KV 支持 TTL，过期值不可读取也不计入配额。桌面完整包在 Launcher“关于应用”中确认后一键更新；服务端包停服后执行 `raylea-server update apply`。
- **插件直接使用本机能力**：删除插件权限声明、宿主代理的 HTTP 请求与文件存储；插件自行发起网络请求，并读写宿主注入的数据目录。插件管理页改为同源加载，局域网部署不再需要单独的插件页面域名。
- **插件之间的服务调用**：插件可以在 manifest 中声明服务，其他插件经宿主按服务名、版本与方法定向调用，宿主附加调用方身份。凭据等业务数据由提供服务的插件自行保管，例如游戏插件经米游社账号插件取得查询结果。
- **插件专属命令前缀**：插件可以声明自己的命令前缀，管理员可在插件配置中修改，同名命令按前缀区分归属（如 `*体力` 与 `%体力`）。帮助菜单按插件列出生效前缀，用法写成可直接发送的完整命令。

## 其他改进

- **命令解析**：命令只按消息中的文字段解析，@ 等非文字内容不再影响匹配；插件仍可从消息段读取被 @ 的用户。
- **帮助菜单**：插件可以指定自带的帮助命令，“<插件名>帮助”交由插件按自己的样式回复。插件以精确触发声明同一个词时才遮蔽内置菜单，其他插件的宽泛写法不会截走插件的帮助页。
- **日志**：日志时间统一为 UTC 并按 UTC 日期切换文件，管理面仍按配置时区显示；脱敏补充米游社 Cookie、SToken 与抽卡链接中的凭据字段。
- **插件包**：安装包上限提高到 1 GiB、解压总量 2 GiB，以容纳随包分发的模板素材。

## 精简与移除

- **插件安装**：本地插件包一次提交来源并确认信任即创建安装任务；商店插件仅首次安装或来源变化时需要确认。
- **插件管理页**：页面由 `/plugin-ui/<plugin_id>/` 提供，响应 CSP 只允许加载插件包内的脚本，禁止内联脚本与 `eval`；通过 IPv6 字面地址访问时 CSP 无法写出主机，放宽为同源脚本。
- **恢复**：只校验归档完整性与配置、数据库、插件合同版本，不再逐个评估插件，也不生成恢复摘要或要求人工确认。恢复目标中的配置、数据库和数据文件必须不存在，常规做法是恢复到新解压的目录。
- **出站**：删除按目标的出站熔断与每插件消息限流，按目标限流保留。
- **管理与接口**：删除 `/api/system/metrics` Prometheus 接口，外部探活使用 `/healthz` 与 `/readyz`；错误信封删除 `message_key`，客户端按 `code` 处理；管理面移除 OneBot 兼容矩阵面板，矩阵见 [OneBot 兼容说明](../../dev/onebot-compatibility.md)。
- **密钥存储**：删除与密钥同表保存的加密层，平台密钥改为原值保存在独立存储；配置继续只保存 `secret://` 引用，管理面不回显。

## 升级说明

- **升级范围**：适用于 0.5.0 候选的安装与备份。尚未包含一键更新的安装按手动更新：停止服务，执行 `raylea-server backup`，把发布包根目录内容解压覆盖到安装根，再启动。后续版本可使用一键更新或 `update apply`。
- **配置**：配置格式仍为 `schema_version: "4"`。以下已删除的字段按未知字段忽略，不影响加载：`http` 段、`web.plugin_ui_origin_template`、`message.circuit_breaker_seconds`、`message.rate_limit_per_plugin`、`runtime.ipc_action_burst_limit`、`runtime.ipc_pending_actions_max`、`runtime.plugin_init_max_total_seconds`、`log.rate_limit_per_plugin`、`storage.file_max_bytes` 与 `storage.plugin_workdir_soft_limit_mb`。
- **数据**：SQLite 在首次启动时由 `000001` 或 `000002` 逐步事务迁移到 `000003`，其中包括把已加密的密钥改为原值保存；任一值无法解密时整步回滚。迁移后旧版本核心不能读取新结构，退回旧版本需使用旧发布包与升级前的备份。备份清单仍为 v3，0.5.0 候选的备份可以恢复到本版，首次启动时迁移。
- **插件**：插件数据保留在 `data/plugins/<plugin_id>/`。v3 插件保持禁用，安装按 v4 重新构建的版本后再启用。
- **操作方法**：[升级指南](../delivery-and-upgrade.md)、[恢复步骤](../../user/recovery.md)。

## 开发者说明

- **插件合同**：manifest v4、JSONL protocol v4、artifact v2，`min_core_version` 必须为 `0.7.0` 或更高。manifest 删除 `permissions`，init 删除 `effective_permissions`，错误码 `plugin.permission_denied` 删除；宿主动作不再按插件声明授权。见 [Plugin Manifest](../../plugin/manifest.md) 与[插件协议](../../plugin/protocol.md)。
- **网络与文件**：删除 `http.request` 与 `storage.file` 动作，Go SDK 同步删除对应方法。插件使用自带的 HTTP 客户端，持久化文件直接写入环境变量 `RAYLEABOT_PLUGIN_DATA_DIR` 指向的目录；插件包目录经 `RAYLEABOT_PLUGIN_PACKAGE_DIR` 传入，包内随附文件只读。
- **出图**：`render.image` 资源新增 `path`，引用数据目录内插件自行下载或生成的文件，数据目录没有时读取插件包内的同一路径；单次最多 512 项，其中 `url` 项仍最多 16 项。资源另接受字体（以资源 ID 注册为字体族），图片同时以 CSS 自定义属性 `--render-resource-<id>` 提供给整页样式，带 `data-render-resource` 的非图片元素可用 `var(--render-resource)` 作背景。`template.json` 新增 `fit_width`，出图宽度可随页面内容确定；`body` 隐藏溢出时高度按 `body` 自身的盒子测量。见[插件协议](../../plugin/protocol.md)与 [Plugin Manifest](../../plugin/manifest.md)。
- **服务调用**：manifest 新增 `services`，协议新增 `plugin.call` 动作、`plugin.request` 事件与服务路由错误码，Go SDK 提供服务声明与调用。协议没有取消帧，调用期限与失败语义见[插件协议](../../plugin/protocol.md)。
- **命令与帮助**：manifest 新增 `command_prefixes`，`init.command_prefixes` 改为下发对该插件生效的前缀；pattern 触发器新增 `fallback`，兜底命令只在所有插件的普通命令与内置帮助菜单都未命中时参与匹配；`help.command` 指定插件自带的帮助命令，须为 exact 触发。
- **计划任务**：新增 `scheduler.delete` 动作与 Go SDK 的 `SchedulerDelete`，插件只能删除自己创建的任务。
- **Webhook**：manifest 声明只保留 `id`、`route`、`source_cidrs` 与 `max_body_bytes`，删除内置 token、签名、secret 引用与重放保护。`webhook.received` 的 `raw_payload` 携带请求头，并以 `body_text` 或 `body_base64` 保留原始正文，插件按对方平台规则自行验签与去重。
- **管理页**：bridge v3 退役。`@rayleabot/plugin-ui` 以当前管理会话直接调用管理 API，并读取宿主主题变量；外部 CDN 脚本和内联脚本会被 CSP 拒绝，需打包进插件管理页资源。见[插件管理页](../../plugin/management-ui.md)。
- **对话、优先级与 KV**：新增 `session.wait`、`session.finish` 与 `session.expired`，manifest 新增 `priority` 与 `block`，KV 写入支持期限。见[插件 SDK](../../plugin/sdk/README.md)。
- **帧校验**：正式插件不再逐帧校验协议消息，只有 `plugin dev-sync` 安装的开发插件校验入站帧并给出诊断；单帧大小上限、stderr 截断，以及每个插件进程最多 256 个未完成 action 的上限保留，超出时返回 `platform.rate_limited`。插件构建不再生成 SBOM，许可证与第三方声明保留。

## 验证范围与发布限制

本说明对应的源码已通过仓库测试、契约与生成物检查、仓库内示例插件构建，以及基于真实 Server 的 Web 冒烟。平台包构建、实包安装与各平台验收完成前，本版不代表正式发布；不同提交的构建不能沿用另一份候选包的验收结果。

macOS 候选包采用链接器 ad hoc 签名，不包含 Developer ID 签名、公证或 Gatekeeper 验收。
