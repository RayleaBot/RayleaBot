# 执行计划

执行计划描述待实施的设计、依赖和验收条件。当前已提供的接口仍以 [contracts](../../contracts/README.md) 为准。

| 计划 | 范围 | 状态 |
| --- | --- | --- |
| [通用插件服务调用](./plugin-services.md) | 静态服务声明、定向调用、SDK 与运行生命周期 | S1–S4 已实现并提交；协议不含取消帧，服务声明不设版本门槛 |
| [游戏插件与账号服务](./game-plugins/README.md) | 三个独立游戏插件、独立账号插件、功能迁移与参考清单 | 2026-09-20 审计后进入返工，见[返工计划](./game-plugins/rework-plan.md) |

两项计划按先通用通信、后业务接入的顺序实施。业务数据、加密、登录和调用许可由提供服务的插件维护，宿主只负责通用通信和运行状态。
