# 执行计划

执行计划描述待实施的设计、依赖和验收条件。当前已提供的接口仍以 [contracts](../../contracts/README.md) 为准；已落地并写入现行文档的计划不再保留。

| 计划 | 范围 | 状态 |
| --- | --- | --- |
| [游戏插件与账号服务](./game-plugins/README.md) | 三个独立游戏插件、独立账号插件、功能迁移与参考清单 | R0–R6c 完成，R7 验收与交付未开始，见[返工计划](./game-plugins/rework-plan.md) |

业务数据、加密、登录和调用许可由提供服务的插件维护，宿主只负责通用通信和运行状态；宿主侧的服务调用与后台事件语义见[插件协议](../plugin/protocol.md)。
