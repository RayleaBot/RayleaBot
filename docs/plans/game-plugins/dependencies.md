固定 MihoyoBBSTools 与逍遥参考使用独立 `x-rpc-combo_token`，当前[上游使用说明](https://github.com/Womsxd/MihoyoBBSTools#获取云原神的-token)仍要求云客户端授权；未找到可验证的米游社 CK/SToken 直接换取路径。其授权获取保留为外部依赖，不影响三游戏常规 CK 共享。功能适配与账号插件内的加密配置继续实施；不在聊天或普通配置收取明文 Token。云钱包 GET 可能同时发放免费时长，相关操作需按有副作用处理，不能冒充纯状态查询。
