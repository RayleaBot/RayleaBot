# 四插件交付与验收

日期：2026-09-19。版本：0.1.0（本地交付）。非受限执行台账已完成；原参考的额外非游戏业务继续保持范围待定。

## 交付内容

四个独立运行插件为 `raylea.mihoyo-accounts`、`raylea.genshin`、`raylea.starrail`、`raylea.zzz`。`game-plugin-kit` 仅为编译期依赖。三游戏增强直接包含在各游戏中，账号凭据仅在账号插件内加密保存和代理使用。

安装包位于主工作区同级的 `RayleaBotPlugins/plugin-*/dist/artifacts/`，每个插件提供 Windows x64、Linux x64、macOS arm64。每份包内 `ui/source.zip` 包含该插件、同版本编译期库及 SDK 对应源码；管理页页脚可下载。SDK/业务库公开 tag 尚未发布，源码包使用随包工作区替换依赖。

## 原生行为对应

- 命令使用三游戏标准前缀与各自清单；原隐式触发和修改其他插件优先级由显式入口、别名冲突策略及群设置替代。
- 图鉴/攻略图片通过本地有许可素材导入或官方原图链接使用；不随包分发未核实授权的素材库。
- 星铁在线时长按自然恢复记录估算，明确字段缺失和覆盖范围。消费记录为官方游戏资产变化，不冒充实际付款账单。
- 群排行与圣牌交换通过本人主动提交加入；交换仅匹配，不执行赠送。
- 原 miao 上传深渊入口在固定快照仅生成报告，未调用其占位上传方法；保留当前可观察行为。
- 业务ZIP每次按一个分类校验并恢复到空目标，不包含凭据、密钥或定时委托；账号备份使用独立加密流程。

## 剩余条件

真实海外账号、绝区零当前设备验证、星铁国服完整逐抽/摘要授权、云游戏单独授权来源、真实 ark/OCR/上传、地图服务 HTTPS 故障、未明确的资源分发许可、公开发布及其他系统实机验收见[依赖登记](./dependencies.md)。这些项目保留在完整目标内。
