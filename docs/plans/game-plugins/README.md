## 已确定的实施方向

- 四个独立插件：原神、星穹铁道、绝区零、米游社账号管理；增强功能并入对应游戏插件。
- 宿主实现 `services`、`plugin.call`、`plugin.request` 等通用能力，公开字段与路由实现不绑定具体业务。
- CK 加密、密钥、扫码、刷新、账号授权和业务 API 适配只在账号插件；游戏插件通过服务获得无凭据业务结果。
- 默认所有插件可信，沿用当前管理页和权限模型；界面分离显示并隐藏明文凭据。
- 全部云功能保留，优先接入现有服务；先交付国服，海外仍在完整目标中。
- 功能结果完整复现，界面与管理使用 RayleaBot 原生方式。
