# RayleaBot Web Management UI

本规范定义 `web/` 管理面的视觉与交互映射。项目级颜色、字体、层次和组件规则以根目录 [`DESIGN.md`](../../DESIGN.md) 为准；工程约束以 `web/AGENTS.md` 为准。

## 工程边界

- 应用壳、认证入口和全部正式工作区使用 Reka UI 与产品自有组件；shadcn-vue 源码由仓库维护。
- HTTP、WebSocket、Pinia store、generated types 和路由语义保持现有正式来源。
- `design/tokens.json` 通过生成脚本提供 CSS variables，Tailwind 和产品组件消费相同的语义 token。
- 页面局部样式只负责业务布局和无法由组件 token 表达的最小差异。
- 品牌、页面与面板标题、普通正文、控件及插件卡片版本使用共享的 HarmonyOS Sans SC：`--font-display` 与 `--font-sans` 都以它为首选，产品组件通过 CSS 继承字体。三个未经修改的 TTF 与许可协议随 Web 构建发布，“偏好设置 › 外观”底部以一行说明声明使用了该字体。
- 日志消息正文使用界面字体；日志行的时间、来源与技术元数据，详情中的来源、插件 ID、请求 ID，以及结构化数据与 JSON 使用等宽栈。独立 iframe 的字体遵循插件自己的规范。
- `DESIGN.md` 前置数据、`.impeccable/design.json` 与共享字体 CSS 由 `scripts/generate-design-tokens.mjs` 维护，设计正文变化由生成器同步到 sidecar 的 narrative。

## 主题映射

主题偏好包含 `system`、`light` 和 `dark`。首次显示使用 `system`，显式选择保存在本地偏好中；亮暗主题提供相同的内容、状态和操作能力，不提供按时钟自动切换配置。页面是白色画布（暗色主题为近黑）；侧栏、卡片、对话框、抽屉、菜单与提示条都是浅灰盒子，不加边框，只以柔和阴影分层。控件取所在容器相反的明暗：位于页面上的次要按钮与分段轨道是浅灰，位于盒子里的是白色，都以轻阴影抬升；输入框始终是白底加控件边界。蓝色只用于主操作、链接、焦点与选中导航的图标，不使用渐变、背景模糊或半透明材质。

favicon 由现有 `resolvedThemeMode` 同步：浅色引用 [`favicon.svg`](../../web/public/favicon.svg)，暗色引用同一母版生成的 [`favicon-dark.svg`](../../web/public/favicon-dark.svg)，与界面标识使用同一有效主题。

## 应用壳

- 桌面侧栏是悬浮在白色页面上的浅灰盒子，与视口四周保持间距、以柔和阴影抬升；当前页面项是带轻阴影的选中胶囊，文字加粗、图标取品牌前景色，不使用彩色侧边条。品牌入口使用共享黑白人物标识，浅色主题显示原版，暗色主题将填充与描边整体反色，保留母版曲线、手势与透明背景。
- 侧栏顶级入口包含“系统状态”“插件中心”和“协议中心”，其余页面归入“治理”“运行与诊断”“系统”。“插件中心”是使用插件图标的顶级入口；展开的侧栏进入持久插件中心层，从其他业务页面进入时默认打开 `/plugins`。收起侧栏通过弹出菜单提供五个固定入口，不展开全部插件列表。其余分类保留展开与收起能力。
- 展开侧栏的分类标题使用原生按钮，仅显示文字与展开箭头；使用中性辅助色的小号文字。分类标题保持透明背景，不套用普通导航项的底色；展开或包含当前页面时不单独增加装饰。
- 分类标题使用可点击光标，保留整行展开/收起、键盘导航与中性 `focus-visible` 轮廓。粗指针环境下导航项使用触控尺寸的点击目标；普通页面项保留悬停反馈和当前页标记。收起侧栏通过键盘可达的弹出菜单提供子项。
- 管理壳没有独立的顶栏和面包屑，每页第一行由 `AppPage` 提供：左侧是可选的状态标识、标题与说明，右侧依次是页面搜索与本页操作。页面搜索是带 `Ctrl K`（macOS 为 `⌘ K`）提示的胶囊，与快捷键打开同一搜索面板。
- 软件名后显示构建时写入的版本；开发服务和未指定发行版本的构建显示“开发版本”。侧栏底部依次是账号菜单、主题切换与折叠侧栏按钮；账号菜单收纳修改账号、偏好设置、全屏、退出登录与关闭服务，关闭服务经过危险确认。收起侧栏时三者纵向排列并保留图标入口。
- 账号菜单按需打开“修改账号”弹窗，先展示当前密码、新密码与确认密码；“同时修改用户名”展开可选用户名字段。校验错误关联字段并聚焦首个错误，提交期间阻止重复提交与关闭，成功后返回登录页。
- 主题切换从操作入口向全页展开新主题，使用 Motion 驱动 View Transition 快照的 `clip-path`，时长为 `420ms`；无入口坐标时使用 `280ms` 淡入。弹窗复用 Motion 的进入、退出与内容高度过渡，取消后归还账户入口焦点。减少动态效果时即时切换状态。
- 管理壳只有一个工作区，切换页面直接替换当前内容。路由声明 `keepAlive` 的页面首次访问后保留缓存，再次进入时恢复草稿、筛选与滚动位置；只改变查询参数时按 `viewKey` 复用同一页面实例。未声明缓存的页面（如系统状态与插件详情）离开后释放，再次进入时重新读取。
- 展开侧栏中的“插件中心”按“管理”“工具”“已安装插件”分组呈现五个固定页面和插件列表。每个插件都能独立展开概览与 manifest 声明的内置管理页，展开或收起一个插件不改变其他插件的展开状态；当前路由对应的插件自动展开，其他插件保持可见并可直接切换。每个插件行是一个整体胶囊：打开中的插件与悬停的插件行使用同一中性底色，打开中的插件名称加粗，行内的名称与展开按钮不再叠加第二层底色。插件中心标题返回主导航时不改变当前 URL 或工作区内容。
- 页面搜索使用统一深链；插件详情具有独立页面标题。侧栏选择插件时进入其概览；折叠侧栏时使用详情页内的分段控件。
- 菜单保存与未保存状态位于左侧字段下方；商店刷新、目录来源与条目数量位于筛选工具栏；指令权限入口位于指令筛选旁。插件列表安装入口及全局插件设置保存栏保持各自位置。必要的字段说明、业务状态、错误与空态信息保留。
- 相同配置快照的重复读取保留菜单中心和全局插件设置的本地草稿，配置更新与保存结果按各页面规则同步。
- 页面主操作位于页面首行或对应工作区的稳定位置，同一区域保持一个蓝色主按钮；按钮统一为胶囊形，主按钮使用白色文字，次要按钮使用与所在容器明暗相反的控件填充。
- Attention 操作只出现在人工确认、可信代码确认或需要明确判断的上下文中。

## 状态与偏好

- 内部状态色调统一为 `neutral`、`info`、`success`、`warning`、`attention` 和 `danger`。普通停止与未知状态降为中性，初始化、配置草稿和可信代码确认使用 attention，警告与失败不能与 attention 混用。
- 偏好设置抽屉分为外观、工作区和快捷键三栏，快捷键栏只列出可用组合键。
- 表单页（黑白名单、权限、限流、全局插件设置与通用配置）在任何内容宽度下都限宽 `1120px` 并在工作区居中；内容宽度使用“自适应”时，其他工作区占满壳层提供的可用宽度，使用“固定”时，数据页与详情页分别使用递减的最大宽度。
- 紧凑密度只减少页面留白和分区间距，不缩小正文、状态标签或关键操作目标。

## 页面组合

- 数据工作区遵循内容宽度偏好，表格、日志和模板预览不放入多层卡片；表单、列表、日志和普通内容放在浅灰盒子里，嵌套在盒子里的列表与视口直接排在所属盒子上，不叠加第二层盒子；盒子里的空状态插图不垫底块。
- 表单主体始终限制最大宽度并居中，通用配置同样以居中的分类工作台呈现。字段说明紧邻控件，连续说明文本限制行宽。
- 独立对象、独立操作或需要整体移动的内容可以使用独立盒子；同一工作流内的字段组使用标题、间距和分隔线。
- 状态总览优先使用紧凑胶囊、分区和状态标签，不使用巨型数字加辅助统计的 hero 指标模板。
- 系统状态页首行是整体状态标识、标题与“运行状态 · 已运行时长 · 服务端核实时间”的说明，右侧依次是页面搜索、“重新检查 | 导出诊断包”操作组与“创建备份”主操作。
- 存在需要人工处理的就绪问题或诊断问题时，首行下方的浅灰盒子汇总数量与首要问题，提供“查看检查”和一次准备全部缺失运行资源的“准备运行环境”；同一问题代码只计一次。没有待处理问题时不显示该盒子。
- 下方两行两列的浅灰盒子依次是协议连接、运行信息、检查与近期变化。协议连接逐行列出机器人连接并链接到对应配置，末尾提供添加入口；运行信息列出版本与更新检查、数据库、配置、管理面地址和实时推送状态；检查以分段控件切换就绪检查与运维诊断，问题行排在检查行之前，原始代码留在可展开详情；近期变化只列系统与连接事件，连接事件链接到协议中心。
- 状态页不展示插件，插件的运行状态与问题由插件中心和日志承担；插件相关的就绪或诊断问题仍进入需要处理的汇总。
- 内容来自现有系统数据，不补充装饰指标。
- 状态行与检查行的图标位于对应状态色的淡色圆角方底中，状态以图标加文字表达；其他功能图标不使用装饰性底盘。
- 错误和警告使用无底色的紧凑状态行，语义色只用于图标或小型状态标签；标题、影响和操作相邻，不使用横贯工作区的彩色横幅。
- 普通加载失败使用工作区内居中的状态说明与重试操作，不铺设背景或外框；只有正式 403、404、500 和离线路由使用整页异常状态。
- 插件以独立卡片呈现：每个插件是浅灰盒子，停用插件的图标降为灰度，异常插件加对应色调的描边环。插件列表没有外层卡片，筛选工具直接位于页面上。卡片使用自然内容高度。插件卡片展示图标、名称及其后的版本、描述、安装来源类型、信任与运行状态；ID、安装根目录和作者保留在概要或详情，不在卡片外显。图标仅通过受认证接口读取清单声明的资源；未声明或加载失败时使用共享 RayleaBot Logo。采用同排等高、操作栏底部对齐的四至五列网格，不以紧凑数据行替代。
- 插件卡片底部提供概要、管理、重载和启停入口，每个入口具有可访问名称；“管理”使用带设置图标的文字按钮，直接打开插件声明的首个内置管理页，未声明管理页时进入概览。重载与启停保留禁用、处理中反馈，以及现有生命周期限制和确认行为。概要、重载和启停图标在粗指针环境使用触控尺寸的点击目标。指令与别名通过既有概要和详情查看，卡片不显示指令清单。
- 概要使用预览眼睛，管理使用设置图标和文字，重载使用双箭头，启停使用播放／停用图形；各操作使用盒子里带轻阴影的白色圆形或胶囊按钮，启停图形随当前状态切换，图标操作通过悬停提示说明具体动作。
- 指令与定时任务使用紧凑数据表或数据行。
- 协议中心的连接卡片以账号头像、用户名和平台号码为主体；每个连接是浅灰盒子，异常连接加对应色调的描边环；OneBot11 显示 QQ 号，官方机器人显示平台机器人 ID。协议类型与文字状态位于顶部，配置连接标识保持次级层级；身份未知或头像加载失败时使用默认头像，未连接或身份未知时补充运行摘要，长名称、号码与摘要可换行。连接标识、配置与删除位于底部，同排操作区底部对齐，粗指针下使用触控尺寸的操作目标。添加和配置在居中弹窗内完成，协议选择只在添加弹窗的首步显示。连接方式与凭据按所选协议渐进披露，草稿保留在弹窗中，关闭前确认放弃未保存修改。
- 实时日志与历史日志复用筛选控件和详情工作区。桌面筛选常驻，级别与来源直接可见，协议、插件和请求 ID 收纳在带已选数量提示的紧凑筛选浮层中；筛选工具与应用操作保持同轴，历史日志的时区写在时间字段的标签里，日志只使用一个外框，正文保留独立纵向滚动与跟随最新行为。
- 筛选栏编辑的是草稿：只有“应用筛选”或快捷时间范围会改变列表的查询、实时匹配与翻页条件，草稿与已应用条件不同时在应用按钮旁显示“筛选未应用”。快捷时间范围以按下状态标出当前生效的范围，手动改过时间后不再标出，再次选择当前范围会以现在为终点重新读取。
- 日志行依次排列时间、级别、来源与协议标签、以插件名开头的消息，短消息保持单行，长消息换行；服务端给不属于任何请求的日志填入的保留请求 ID `system` 不显示，也不提供相关日志入口。悬停使用中性底色，选中行使用选中淡面加内描边；实时日志打开详情时暂停跟随最新。
- 日志详情窗与对话框一致，使用浅灰表面和浮层阴影，不加边框与页头色带；先呈现消息正文，再列出页头之外的插件与请求 ID，随后保留关联操作与结构化 JSON。正文与 JSON 放在无边框的白色内嵌底上，按各自字体角色显示。
- 日志无匹配结果时明确说明“没有符合条件的日志”；历史日志提供扩大时间范围或调整筛选的方向，实时日志提供调整筛选或等待新日志的方向。空结果不使用破折号表示，也不填充示例日志。
- 通用配置按基础与访问、图片生成、调度、插件运行、数据与存储、日志与消息分为六类。左侧分类导航使用同一套线性图标。高级参数在所属分类内展开，搜索名称、说明或字段路径时直接展示匹配字段。
- 分类切换与搜索保留同一份草稿，右下方的单一悬浮按钮统一保存，浮标组位于表单列右侧的留白中，不覆盖字段；分类内容较短时按钮停在工作区右下角，内容较长时随滚动悬浮。按钮复用浮层阴影；未修改时保持中性表面，未保存时使用人工关注色与数量角标，保存中显示加载图标，失败改用 danger 和错误图标，成功恢复中性。完整状态通过 Tooltip 和 `aria-describedby` 提供，`role=status` 播报变化；无修改时标记 `aria-disabled`，仍可聚焦读取说明。存在修改时，保存按钮左侧出现中性撤销浮标，两个按钮垂直居中；保存按钮的位置保持稳定。
- 新配置快照保留本地已改字段，重叠修改在编辑区提示；保存失败保留草稿并提供重试，离开时确认放弃修改。初次加载、无匹配结果、保存中和需要重启的结果均有对应状态，保存后仍需重启时编辑区顶部持续提示。每行都保留单位列，控件右缘对齐；分类的选中项与侧栏一致，是抬起的中性胶囊，只有图标为蓝色，“已修改”使用人工关注色。
- 全局插件设置、权限、名单和限流使用稳定目录、分区表单和按需保存栏；草稿状态使用人工关注色，名单为空的白名单风险持续可见。名单读取失败时在对应名单内说明并提供重试，不显示成空名单或可拨动的开关；刷新失败时保留上次读取的条目并说明。
- 全局插件设置、权限策略与限流中心共用分区行（左侧分区名与图标，右侧字段）和单一底部 sticky 保存栏，贴合工作区底部（`bottom: 0`）；只有一个字段的分区以分区名作为可见标签，控件保留字段全名供读屏使用，字段说明直接写在控件下方。未保存与保存结果通过保存按钮左侧同一位置的 `aria-live` 状态区反馈，保存按钮保持在该栏内。保存处理、禁用与加载状态及内容宽度偏好保持一致，表单正文、字段和保存栏使用实底。粗指针环境保留字段与触控目标尺寸；插件自定义页面宿主开关与相邻操作采用触控尺寸的目标。

## 动效与切换

- 控件反馈使用 `100–160ms` 短节奏，当前标准反馈为 `160ms`；内容与工作区使用 `180–220ms`，浮层使用 `200–220ms`。动画只承担可见反馈，不构成稳定帧率承诺。
- 管理工作区使用元素级 View Transition，切换只捕获主内容，侧栏在动画期间保持稳定且可交互；主题切换使用根快照交叉淡化。
- 页面偏好 `fade` 使用透明度切换，`fade-slide` 只增加轻微的垂直位移，`none` 立即替换内容。内容切换固定为 `200ms`。旧页面在切换时立即移除，只有新页面淡入，两个页面的内容不叠加显示。
- 已有内容的页面重新读取时保留当前内容，骨架屏只在还没有可显示的内容时出现。
- View Transition 不可用、浏览器历史导航或未包装导航使用 Motion for Vue 的 DOM animate 能力降级；连续导航取消旧动画，以最新路由为准。
- 同一元素不叠加 View Transition、Motion 和 CSS 动画。内容切换期间保持工作区可见，日志追加不逐条播放进入动画；`prefers-reduced-motion` 或 forced-colors 下导航和主题立即完成。

## 浮层

- 菜单、选择器浮层、说明弹层、提示条、Modal 与侧边 Drawer 都是浅灰盒子，以浮层阴影抬升，不模糊背后的内容。Modal 使用大圆角面板，遮罩是纯色压暗（浅色主题 28%、暗色主题 50% 的黑色）；侧边 Drawer 是悬浮在视口内的圆角面板。遮罩、层级与 Tooltip 规则见 [`DESIGN.md`](../../DESIGN.md) 的 Elevation & Depth。
- 菜单项高亮是带轻阴影的白色胶囊，危险项使用危险淡面；浮层里的控件与盒子里的控件一样使用白色控件面。
- forced-colors 下盒子与浮层使用系统颜色与边界并去掉阴影。

## 认证入口

- 登录、首次初始化与凭据恢复指引共用居中单栏面板。
- 认证表面沿用共享黑白人物标识、HarmonyOS Sans SC 和 Web 局部语义 token。面板是白色页面上的浅灰盒子，以柔和阴影抬升；标识方块、字段与底部文字操作的悬停面是白色控件面，主按钮为蓝色，文字、控件与链接颜色由认证主题 token 映射。亮暗主题保留相同的信息、验证和提交能力，共享品牌 token 表达统一的颜色和字体语义。
- 页面只保留产品身份、任务标题、必要说明和凭据表单，不使用 hero 或功能宣传。
- 认证页与管理工作区同为白色页面，不使用背景图片或背景动画。
- forced-colors 下面板使用系统颜色与边界，焦点使用系统高亮色。
- 认证布局进入时执行透明度与轻微垂直位移动画，切换恢复指引不重复播放；reduced-motion 环境即时呈现。
- 面板标题、凭据输入与主按钮使用认证入口专用尺寸；主题切换、底部文字操作与密码显隐按钮保留触控尺寸的点击目标。
- 字段交互参考 Apple [Text fields](https://developer.apple.com/design/human-interface-guidelines/text-fields)，认证输入沿用 Web 的贴边焦点几何：边框搭配内侧描边，不使用外扩光环。forced-colors 下使用内侧系统轮廓；主按钮、主题切换和文字操作保留可见键盘焦点。
- 字段使用标准输入控件和持续可见标签；字段错误就近显示，校验失败聚焦首个无效字段，服务错误与状态异常显示在表单反馈区。登录使用 `current-password` 自动填充，初始化使用 `new-password`；提交期间保留禁用与加载反馈。
- 登录面板的“忘记密码？”打开“重置管理员凭据”指引并聚焦标题；“返回登录”保留已填凭据，将焦点归还“忘记密码？”入口。浏览器只展示操作指引，不执行凭据重置。
- 启动器路径为“设置 → 维护操作 → 重置凭据 → 立即重置”，确认后由启动器停止服务并重置。命令行路径要求先停服，再于安装目录运行：Windows PowerShell 使用 `.\raylea-server.exe reset-admin`，macOS / Linux 使用 `./raylea-server reset-admin`；自定义配置通过放在子命令之前的 `-config` 参数指向原配置文件。
- 重置后启动服务，从初始化入口重新创建管理员账号；配置、数据和已安装插件保留，旧登录会话失效。恢复语义遵循 [`cli-commands.yaml`](../../contracts/cli-commands.yaml) 与[管理面用户说明](../user/management-surface.md)，登录、初始化和会话接口沿用现有请求层与 store。

## 组件状态

- 管理工作区文本选区使用浏览器和操作系统的默认高亮；认证区域通过局部 `::selection` 使用现有品牌填充与对应前景。菜单、页签等控件的选中态独立使用组件主题。
- 按钮、输入、选择器、页签、导航、表格行和可点击表面覆盖默认、悬停、焦点、按下、禁用、加载和错误状态；分类标题的悬停与焦点反馈以应用壳规则为准。
- 按钮、输入框与选择器的默认高度以 [`DESIGN.md`](../../DESIGN.md) Components 中对应的产品组件为准；粗指针环境使用触控尺寸的可点击目标。认证控件使用认证入口规定的局部尺寸。
- 分类工作台的字段说明直接显示在名称下方并关联控件，默认值由字段元数据提供，并在输入框为空时作为 placeholder 显示；占位文本不回填草稿，显式示例提示优先，数字、文本、列表和拆分限流控件均沿用该规则；其他紧凑表单复用可点击、可键盘操作的 `AppHelp` 浮层，关闭后归还焦点。`AppField` 的普通提示和错误均关联输入控件；开关可以保持紧凑外观，但扩展点击区域须预留布局空间，不覆盖相邻控件。正常读取配置的凭据脱敏不产生全页通知。
- 减少动态效果按控件、浮层和载入反馈分别处理，保留静态忙碌状态，不使用全局极短动画时长覆盖所有元素。
- 管理页面标题、分区标题、正文和辅助信息沿用 `DESIGN.md` 的字号层级；认证标题使用专用字号，紧凑布局不使用装饰性眉题或流式巨型标题。
- 焦点在控件现有边界内呈现：输入、文本域、选择器和标签输入使用边框着色与内侧描边；其他控件使用内侧轮廓，偏移统一由 `--focus-outline-offset` 提供。轮廓与相邻背景至少达到 `3:1`，不叠加外扩光环、额外间距或父容器外框；认证与 forced-colors 使用各自颜色。
- 加载状态使用与最终内容形状一致的骨架；空态说明原因、前置条件和可执行动作。
- 状态标签同时包含文字或图标，颜色不作为唯一信息。

## 视口与布局

独立的文本、密码、数值、文本域与单选编辑字段使用 `AppField floating`。字段名称在空值且未聚焦时位于框内，聚焦或已有值时移至框内上方，以小号文字持续可见；自动填充与数字零也视为已有值。示例占位文本在聚焦后可见，标签不替代必填、错误或说明关联。前缀图标与密码显示按钮各自保留空间，减少动态效果时标签位置直接更新。

文本域上沿为标签保留固定区域，长文本滚动时正文不会遮挡标签。

该模式用于登录与初始化、修改账号、协议连接、插件安装、商店源编辑、全局插件设置中的单值字段，以及日志筛选浮层中的协议和请求标识。日志筛选栏常驻的级别与来源字段使用顶部标签并按顶边对齐；配置工作台的左右说明行、复合限流、开关、标签列表、多选筛选、日期时间范围和表格列标题保持各自的标注方式。

Web 管理面只提供桌面布局，以 16:9 的 `1920×1080` 为最低分辨率与界面验证基准；手机、平板与低于该分辨率的桌面窗口不在支持范围，不提供抽屉导航、摘要行或折叠筛选等窄屏结构。桌面始终显示完整侧栏与单一工作区，页面首行容纳标题、页面搜索与本页操作，多列只用于真实并行任务。

更宽的屏幕只增加网格列数，不切换导航或列表结构，不使用流式标题字号，也不删除正式功能。代码、长路径和技术字段可以在所属区域局部横向滚动；普通业务页面不得产生页面级横向滚动。

插件网格在 `1920` 宽的桌面为四列，视口宽度达到 `2300` 时增加到五列，断点以组件代码为准，内容仍遵循工作区宽度偏好。插件卡片保持统一最小高度，长元数据与健康提示可使卡片自然增高，不固定所有行的高度。2K 桌面以每屏约 10–15 张完整卡片为密度目标，可见数量随内容、视口高度和宽度偏好变化，不保证在所有内容条件下成立。

## 验收条件

- 首次主题跟随系统，显式亮暗选择可持久化，切换后无不可读或缺失状态。
- 主文本、次文本、链接、按钮、控件边界、焦点和语义状态达到 WCAG 2.2 AA，并支持 forced-colors。
- 页面符合 [`DESIGN.md`](../../DESIGN.md) 的 Do's and Don'ts；独立插件集合保留卡片网格，不把该例外扩展为所有数据页的布局。
- 插件卡片状态可读，管理入口和图标操作可通过键盘辨认和触发；全局插件设置的草稿反馈和保存入口位于同一稳定区域。
- 页面为白底，盒子为浅灰并只以阴影分层，控件取所在容器相反的明暗；不使用渐变、背景模糊或半透明材质，forced-colors 下使用系统颜色与边界。
- 认证入口在亮暗主题下保留字段和操作；恢复指引往返保留凭据与焦点，说明中的停服、本机重建和会话失效条件清楚可见。
- 页面使用产品组件，复用现有请求层、WebSocket 封装、Pinia stores 和管理深链 helper。
- `prefers-reduced-motion` 下移除非必要过渡，状态变化仍能立即理解。
