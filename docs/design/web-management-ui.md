# RayleaBot Web Management UI

本规范定义 `web/` 管理面的视觉与交互映射。项目级颜色、字体、层次和组件规则以根目录 [`DESIGN.md`](../../DESIGN.md) 为准；工程约束以 `web/AGENTS.md` 为准。

## 工程边界

- 应用壳、认证入口和全部正式工作区使用 Reka UI 与产品自有组件；shadcn-vue 源码由仓库维护。
- HTTP、WebSocket、Pinia store、generated types 和路由语义保持现有正式来源。
- `design/tokens.json` 通过生成脚本提供 CSS variables，Tailwind 和产品组件消费相同的语义 token。
- 页面局部样式只负责业务布局和无法由组件 token 表达的最小差异。
- 品牌、页面与面板标题、普通正文、控件及插件卡片版本使用共享的 HarmonyOS Sans SC：`--font-display` 与 `--font-sans` 都以它为首选，产品组件通过 CSS 继承字体。三个未经修改的 TTF 与许可协议随 Web 构建发布，“偏好设置 › 外观”声明使用了该字体并链接协议原文。
- 日志消息正文使用界面字体；日志行的时间、来源与技术元数据，详情中的来源、插件 ID、请求 ID，以及结构化数据与 JSON 使用等宽栈。独立 iframe 的字体遵循插件自己的规范。
- `DESIGN.md` 前置数据、`.impeccable/design.json` 与共享字体 CSS 由 `scripts/generate-design-tokens.mjs` 维护，设计正文变化由生成器同步到 sidecar 的 narrative。

## 主题映射

主题偏好包含 `system`、`light` 和 `dark`。首次显示使用 `system`，显式选择保存在本地偏好中；亮暗主题提供相同的内容、状态和操作能力，不提供按时钟自动切换配置。应用根部是暖石灰光场：中性画布上叠五层柔和的径向光晕，暗色主题使用炭色画布与更暗的光晕。表单、列表与日志使用实色表面；运行中、已连接或已就绪的对象使用点亮表面，它在两种主题下都是浅色；导航层、悬浮控件、浮层和未点亮的对象使用液态玻璃。橙色只用于主操作与品牌强调，品牌链接使用加深的品牌前景色。

favicon 由现有 `resolvedThemeMode` 同步：浅色引用 [`favicon.svg`](../../web/public/favicon.svg)，暗色引用同一母版生成的 [`favicon-dark.svg`](../../web/public/favicon-dark.svg)，与界面标识使用同一有效主题。

## 应用壳

- 桌面侧栏是悬浮在光场上的液态玻璃面板，与视口四周保持间距；当前页面项是点亮的近白胶囊，两种主题都使用深色文字，不使用彩色侧边条。品牌入口使用共享黑白人物标识，浅色主题显示原版，暗色主题将填充与描边整体反色，保留母版曲线、手势与透明背景。
- 侧栏顶级入口包含“系统状态”“插件中心”和“协议中心”，其余页面归入“治理”“运行与诊断”“系统”。“插件中心”是使用插件图标的顶级入口；展开桌面侧栏和移动抽屉进入持久插件中心层，从其他业务页面进入时默认打开 `/plugins`。收起侧栏通过弹出菜单提供五个固定入口和已打开插件，不展开全部插件列表。其余分类保留展开与收起能力。
- 展开侧栏的分类标题使用原生按钮，仅显示文字与展开箭头；使用中性辅助色的小号文字。分类标题保持透明背景，不套用普通导航项的底色；展开或包含当前页面时不单独增加装饰。
- 分类标题使用可点击光标，保留整行展开/收起、键盘导航与中性 `focus-visible` 轮廓。移动抽屉使用相同层级并提供触控尺寸的点击目标；普通页面项保留悬停反馈和当前页标记。收起侧栏通过键盘可达的弹出菜单提供子项。
- 页头没有独立底色，面包屑直接位于光场上；导航折叠、搜索和“更多操作”是玻璃胶囊或圆形玻璃按钮，保持单行优先。设置、全屏和关闭服务统一位于“更多操作”；关闭服务经过危险确认。
- 软件名后显示构建时写入的版本；开发服务和未指定发行版本的构建显示“开发版本”。主题切换与账户菜单位于侧栏底部，收起侧栏保留图标入口，移动端使用导航抽屉底部的同一组操作。
- 账户菜单按需打开“修改账户”弹窗，先展示当前密码、新密码与确认密码；“同时修改用户名”展开可选用户名字段。校验错误关联字段并聚焦首个错误，提交期间阻止重复提交与关闭，成功后返回登录页。
- 主题切换从操作入口向全页展开新主题，使用 Motion 驱动 View Transition 快照的 `clip-path`，时长为 `420ms`；无入口坐标时使用 `280ms` 淡入。弹窗复用 Motion 的进入、退出与内容高度过渡，取消后归还账户入口焦点。减少动态效果时即时切换状态。
- 工作区页签位于玻璃胶囊轨道中，当前页签是点亮胶囊。桌面端仅在存在多个工作区时显示页签，移动端隐藏页签。开启“记住工作区”时，正常启动不得清空已恢复页签。
- 工作区页签使用稳定标识；query 变化继续复用既有 `viewKey` 规则。菜单中心、插件商店、插件列表、全局插件设置、指令中心共享“插件中心”页签，其标识为 `/plugins`，返回地址为最后访问子页的完整 URL；各页面的缓存名称与渲染实例保持独立。关闭插件中心释放该组缓存，独立插件详情页签遵循自己的关闭操作。
- 展开侧栏中的“插件中心”按“管理”“工具”“已安装插件”分组呈现五个固定页面和插件列表。每个插件都能独立展开概览与 manifest 声明的内置管理页，展开或收起一个插件不改变其他插件的展开状态；当前路由对应的插件自动展开，其他插件保持可见并可直接切换。插件中心标题返回主导航时不改变当前 URL 或工作区内容。
- 面包屑、搜索和工作区页签使用统一深链；插件详情具有独立工作区页签及页面标题。侧栏优先打开插件工作区页签的完整 URL，没有对应页签时进入概览；折叠侧栏和移动端使用详情页内的分段控件。
- 菜单保存与未保存状态位于左侧字段下方；商店刷新、目录来源与条目数量位于筛选工具栏；指令权限入口位于指令筛选旁。插件列表安装入口及全局插件设置保存栏保持各自位置。必要的字段说明、业务状态、错误与空态信息保留。
- 恢复工作区时，同属插件中心的存储页签合并于该组最早位置，其他工作区保持顺序；当前子页 URL 优先，其次使用统一页签的有效返回地址，否则进入插件列表。相同配置快照的重复读取保留菜单中心和全局插件设置的本地草稿，配置更新与保存结果按各页面规则同步。
- 页面主操作位于页面头或对应工作区的稳定位置，同一区域保持一个橙色主按钮；按钮统一为胶囊形，主按钮使用深色文字与顶部高光。
- Attention 操作只出现在人工确认、可信代码确认或需要明确判断的上下文中。

## 状态与偏好

- 内部状态色调统一为 `neutral`、`info`、`success`、`warning`、`attention` 和 `danger`。普通停止与未知状态降为中性，初始化、配置草稿和可信代码确认使用 attention，警告与失败不能与 attention 混用。
- 偏好设置抽屉分为外观、工作区和快捷键三栏，快捷键栏只列出可用组合键。
- 内容宽度使用“自适应”时，所有工作区占满壳层提供的可用宽度；使用“固定”时，数据页、详情页和表单页分别使用递减的最大宽度。
- 紧凑密度只减少页面留白和分区间距，不缩小正文、状态标签或关键操作目标。

## 页面组合

- 数据工作区遵循内容宽度偏好，表格、日志和模板预览不放入多层卡片；表单、列表、日志和普通内容保持实色表面。
- 固定宽度模式下普通表单主体限制最大宽度；通用配置始终以居中的分类工作台呈现。字段说明紧邻控件，连续说明文本限制行宽。
- 独立对象、独立操作或需要整体移动的内容可以使用有边界表面；同一工作流内的字段组使用标题、间距和分隔线。
- 状态总览优先使用紧凑胶囊、分区和状态标签，不使用巨型数字加辅助统计的 hero 指标模板。
- 系统状态页是设备中控：健康、就绪、启用插件与运行时长是光场上的玻璃摘要胶囊，管理连接状态以紧凑行内排列紧随其后；其下按协议连接、插件、运行环境三组呈现对象磁贴。已连接的连接、运行中的插件和就绪的子系统是点亮磁贴，停用或未就绪的对象是透明玻璃，需要处理的对象加状态色描边；创建备份与导出诊断包是玻璃操作磁贴。磁贴网格按约 170px 自动填充，2K 桌面每行约十余个对象。
- 就绪检查优先显示异常，正常项默认收起；已知检查项使用可读名称，原始代码留在可展开详情。浏览器资源缺失时，在对应异常旁提供现有运行环境准备操作。
- 磁贴下方的宽屏主列展示近期变化、就绪检查与运维诊断页签，辅助列展示正式更新；运维诊断页签只呈现问题详情，子系统概览由运行环境磁贴承担。
- 手机端摘要胶囊与磁贴均为两列，宽磁贴占满一行。
- 内容来自现有系统数据，不补充装饰指标。
- 摘要胶囊的图标位于对应状态色的淡色圆底中，磁贴图标位于对象标识色的圆角方底中；其他功能图标不使用装饰性底盘。
- 错误和警告使用无底色的紧凑状态行，语义色只用于图标或小型状态标签；标题、影响和操作相邻，不使用横贯工作区的彩色横幅。
- 普通加载失败使用工作区内居中的状态说明与重试操作，不铺设背景或外框；只有正式 403、404、500 和离线路由使用整页异常状态。
- 插件以独立设备卡片呈现：运行中的插件是点亮卡片，停用或未运行的插件是填充较密的玻璃卡片，异常插件加描边；点亮卡片是浅色主题小区域，暗色主题下其中的标签、按钮与人物标识仍按浅色主题呈现。插件列表没有外层卡片，筛选工具栏是光场上的玻璃条。卡片使用自然内容高度并在移动端收敛为单列。插件卡片展示图标、名称及其后的版本、描述、安装来源类型、信任与运行状态；ID、安装根目录和作者保留在概要或详情，不在卡片外显。图标仅通过受认证接口读取清单声明的资源；未声明或加载失败时使用共享 RayleaBot Logo。采用同排等高、操作栏底部对齐的一至五列网格，不以紧凑数据行替代；插件筛选在移动端进入底部抽屉。
- 插件卡片底部提供概要、管理、重载和启停入口，每个入口具有可访问名称；“管理”使用带设置图标的文字按钮，直接打开插件声明的首个内置管理页，未声明管理页时进入概览。重载与启停保留禁用、处理中反馈，以及现有生命周期限制和确认行为。概要、重载和启停图标在窄屏或粗指针环境使用触控尺寸的点击目标。指令与别名通过既有概要和详情查看，卡片不显示指令清单。
- 概要使用预览眼睛，管理使用设置图标和文字，重载使用双箭头，启停使用播放／停用图形；各操作使用无边框的圆形或胶囊按钮与淡色填充，启停图形随当前状态切换，图标操作通过悬停提示说明具体动作。
- 指令与定时任务使用紧凑数据表或数据行，在移动端使用摘要行。
- 协议中心的连接卡片以账号头像、用户名和平台号码为主体；已连接的机器人是点亮卡片，其他状态是玻璃卡片，异常连接加描边；OneBot11 显示 QQ 号，官方机器人显示平台机器人 ID。协议类型与文字状态位于顶部，配置连接标识保持次级层级；身份未知或头像加载失败时使用默认头像，未连接或身份未知时补充运行摘要，长名称、号码与摘要可换行。连接标识、配置与删除位于底部，同排操作区底部对齐，窄屏与粗指针下使用触控尺寸的操作目标。添加和配置在居中弹窗内完成，协议选择只在添加弹窗的首步显示。连接方式与凭据按所选协议渐进披露，草稿保留在弹窗中，关闭前确认放弃未保存修改。
- 实时日志与历史日志复用筛选控件和详情工作区。桌面筛选常驻，级别与来源直接可见，协议、插件和请求 ID 收纳在带已选数量提示的紧凑筛选浮层中；筛选工具与应用操作保持同轴，日志只使用一个外框，正文保留独立纵向滚动与跟随最新行为。
- 历史日志在窄屏使用筛选展开按钮，面板默认收起；展开状态通过 `aria-expanded` 表达。成功应用查询或刷新后收起面板，若焦点原在面板内则归还展开按钮；请求失败不收起。折叠不清空筛选字段、草稿或查询状态，实时日志不采用此整体折叠规则。
- 日志详情先呈现消息正文，再以紧凑定义列表呈现元数据，随后保留关联操作与结构化 JSON；正文与技术字段按各自字体角色显示。
- 日志无匹配结果时明确说明“没有符合条件的日志”；历史日志提供扩大时间范围或调整筛选的方向，实时日志提供调整筛选或等待新日志的方向。空结果不使用破折号表示，也不填充示例日志。
- 通用配置按基础与访问、图片生成、调度、插件运行、数据与存储、日志与消息分为六类。左侧分类导航使用同一套线性图标；工作台宽度不足时改为搜索框、分类选择器和单列编辑区，编辑区较窄时字段说明与控件上下排列。高级参数在所属分类内展开，搜索名称、说明或字段路径时直接展示匹配字段。
- 分类切换与搜索保留同一份草稿，右下方的单一悬浮按钮统一保存。按钮复用浮层阴影；未修改时保持中性表面，未保存时使用 attention 暖色与数量角标，保存中显示加载图标，失败改用 danger 和错误图标，成功恢复中性。完整状态通过 Tooltip 和 `aria-describedby` 提供，`role=status` 播报变化；无修改时标记 `aria-disabled`，仍可聚焦读取说明。存在修改时，保存按钮左侧出现中性撤销浮标，两个按钮垂直居中；保存按钮的位置保持稳定。
- 新配置快照保留本地已改字段，重叠修改在编辑区提示；保存失败保留草稿并提供重试，离开时确认放弃修改。初次加载、无匹配结果、保存中和需要重启的结果均有对应状态。
- 全局插件设置、权限、名单和限流使用稳定目录、分区表单和按需保存栏；草稿状态使用暖色 attention，名单为空的白名单风险持续可见。
- 全局插件设置使用单一底部 sticky 保存栏，贴合工作区底部（`bottom: 0`）；未保存与保存结果通过同一位置的 `aria-live` 状态区反馈，保存按钮保持在该栏内。保存处理、禁用与加载状态及内容宽度偏好保持一致，表单正文、字段和保存栏使用实底。窄屏保留字段与触控目标尺寸；插件自定义页面宿主开关与相邻操作采用移动触控尺寸的目标。

## 动效与切换

- 控件反馈使用 `100–160ms` 短节奏，当前标准反馈为 `160ms`；内容与工作区使用 `180–220ms`，浮层使用 `200–220ms`。动画只承担可见反馈，不构成稳定帧率承诺。
- 管理工作区使用元素级 View Transition，切换只捕获主内容，侧栏、页头和固定导航在动画期间保持稳定且可交互；主题切换使用根快照交叉淡化。
- 页面偏好 `fade` 使用透明度切换，`fade-slide` 只增加轻微的垂直位移，`none` 立即替换内容。内容切换固定为 `200ms`。
- View Transition 不可用、浏览器历史导航或未包装导航使用 Motion for Vue 的 DOM animate 能力降级；连续导航取消旧动画，以最新路由为准。
- 同一元素不叠加 View Transition、Motion 和 CSS 动画。内容切换期间保持工作区可见，日志追加不逐条播放进入动画；`prefers-reduced-motion` 或 forced-colors 下导航和主题立即完成。

## 浮层材质

- 菜单、选择器浮层、说明弹层与提示条使用液态玻璃的常规变体：较密的填充与较强的模糊保证文字可读，边缘沿用导航玻璃的高光；材质参数集中在 `web/src/styles/_glass.scss` 的变量中。Modal 使用实色大圆角面板，遮罩带轻度模糊；侧边 Drawer 是悬浮在视口内的圆角面板。遮罩、层级与 Tooltip 规则见 [`DESIGN.md`](../../DESIGN.md) 的 Elevation & Depth。
- 管理工作区的表单、列表、日志与卡片正文保持实色；菜单选中背景和文字保持中性。
- 不支持 backdrop-filter、启用 reduced-transparency 时，所有玻璃回到不透明表面；forced-colors 下隐藏光场并使用系统颜色。

## 认证入口

- 登录、首次初始化与凭据恢复指引共用居中单栏面板；窄屏时缩小圆角并收紧内边距，低高度视口允许页面自然滚动。
- 认证表面沿用共享黑白人物标识、HarmonyOS Sans SC 和 Web 局部语义 token。面板使用管理壳共享的液态玻璃材质，文字、控件与链接颜色由认证主题 token 映射；浅色辅文与底部链接局部加深以保持对比度。亮暗主题保留相同的信息、验证和提交能力，共享品牌 token 表达统一的颜色和字体语义。
- 页面只保留产品身份、任务标题、必要说明和凭据表单，不使用 hero 或功能宣传。
- 认证页与管理工作区共用应用根部的暖石灰光场背景，不使用图片；背景不跟随指针，不参与表单交互。
- 材质参考 Apple 的 [Liquid Glass 介绍](https://www.apple.com.cn/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/)与 [WWDC25 设计说明](https://developer.apple.com/videos/play/wwdc2025/219/)，在浏览器中实现通透面板、圆角边缘折射和反射高光，具体效果按浏览器能力适配。支持 SVG backdrop 的 Chromium 路径使用 `feDisplacementMap`，只使用轻微前置模糊；WebKit 与 Gecko 使用轻度模糊与饱和度的透明材质降级。
- 共享的 [`liquid-glass.ts`](../../web/src/lib/liquid-glass.ts) 按镜片尺寸与圆角生成边缘折射的位移图，中部保持清晰；ResizeObserver 只在尺寸或圆角变化时更新，同尺寸的镜片共享一个滤镜，空闲时没有持续绘制循环。
- 不支持 backdrop-filter，或启用 reduced-transparency、forced-colors 时，面板使用不透明表面；forced-colors 同时隐藏光场并使用系统边界与焦点色。模糊半径不参与动画。
- 认证布局进入时执行透明度与轻微垂直位移动画，切换恢复指引不重复播放；reduced-motion 环境即时呈现。
- 面板标题、凭据输入与主按钮使用认证入口专用尺寸；主题切换、底部文字操作与密钥显隐按钮保留触控尺寸的点击目标。
- 字段交互参考 Apple [Text fields](https://developer.apple.com/design/human-interface-guidelines/text-fields)，认证输入沿用 Web 的贴边焦点几何：边框搭配内侧描边，不使用外扩光环。forced-colors 下使用内侧系统轮廓；主按钮、主题切换和文字操作保留可见键盘焦点。
- 字段使用标准输入控件和持续可见标签；字段错误就近显示，校验失败聚焦首个无效字段，服务错误与状态异常显示在表单反馈区。登录使用 `current-password` 自动填充，初始化使用 `new-password`；提交期间保留禁用与加载反馈。
- 登录面板的“忘记密钥？”打开“重置管理员凭据”指引并聚焦标题；“返回登录”保留已填凭据，将焦点归还“忘记密钥？”入口。浏览器只展示操作指引，不执行凭据重置。
- 启动器路径为“设置 → 维护操作 → 重置凭据 → 立即重置”，确认后由启动器停止服务并重置。命令行路径要求先停服，再于安装目录运行：Windows PowerShell 使用 `.\raylea-server.exe reset-admin`，macOS / Linux 使用 `./raylea-server reset-admin`；自定义配置通过放在子命令之前的 `-config` 参数指向原配置文件。
- 重置后启动服务，从初始化入口重新创建管理员账号；配置、数据和已安装插件保留，旧登录会话失效。恢复语义遵循 [`cli-commands.yaml`](../../contracts/cli-commands.yaml) 与[管理面用户说明](../user/management-surface.md)，登录、初始化和会话接口沿用现有请求层与 store。

## 组件状态

- 管理工作区文本选区使用浏览器和操作系统的默认高亮；认证区域通过局部 `::selection` 使用现有品牌填充与对应前景。菜单、页签等控件的选中态独立使用组件主题。
- 按钮、输入、选择器、页签、导航、表格行和可点击表面覆盖默认、悬停、焦点、按下、禁用、加载和错误状态；分类标题的悬停与焦点反馈以应用壳规则为准。
- 按钮、输入框与选择器的默认高度以 [`DESIGN.md`](../../DESIGN.md) Components 中对应的产品组件为准；窄屏或粗指针环境使用触控尺寸的可点击目标。认证控件使用认证入口规定的局部尺寸。
- 分类工作台的字段说明直接显示在名称下方并关联控件，默认值由字段元数据提供，并在输入框为空时作为 placeholder 显示；占位文本不回填草稿，显式示例提示优先，数字、文本、列表和拆分限流控件均沿用该规则；其他紧凑表单复用可点击、可键盘操作的 `AppHelp` 浮层，关闭后归还焦点。`AppField` 的普通提示和错误均关联输入控件；开关可以保持紧凑外观，但扩展点击区域须预留布局空间，不覆盖相邻控件。正常读取配置的凭据脱敏不产生全页通知。
- 减少动态效果按控件、浮层和载入反馈分别处理，保留静态忙碌状态，不使用全局极短动画时长覆盖所有元素。
- 管理页面标题、分区标题、正文和辅助信息沿用 `DESIGN.md` 的字号层级；认证标题使用专用字号，紧凑布局不使用装饰性眉题或流式巨型标题。
- 焦点在控件现有边界内呈现：输入、文本域、选择器和标签输入使用边框着色与内侧描边；其他控件使用内侧轮廓，偏移统一由 `--focus-outline-offset` 提供。轮廓与相邻背景至少达到 `3:1`，不叠加外扩光环、额外间距或父容器外框；认证与 forced-colors 使用各自颜色。
- 加载状态使用与最终内容形状一致的骨架；空态说明原因、前置条件和可执行动作。
- 状态标签同时包含文字或图标，颜色不作为唯一信息。

## 响应式结构

独立的文本、密码、数值、文本域与单选编辑字段使用 `AppField floating`。字段名称在空值且未聚焦时位于框内，聚焦或已有值时移至框内上方，以小号文字持续可见；自动填充与数字零也视为已有值。示例占位文本在聚焦后可见，标签不替代必填、错误或说明关联。前缀图标与密码显示按钮各自保留空间，减少动态效果时标签位置直接更新。

文本域上沿为标签保留固定区域，长文本滚动时正文不会遮挡标签。

该模式用于登录与初始化、修改账户、协议连接、插件安装、商店源编辑、全局插件设置中的单值字段，以及日志筛选浮层中的协议和请求标识。日志筛选栏常驻的级别与来源字段使用顶部标签并按顶边对齐；配置工作台的左右说明行、复合限流、开关、标签列表、多选筛选、日期时间范围和表格列标题保持各自的标注方式。

| 视口 | 结构 |
| --- | --- |
| 宽屏 | 完整侧栏、页头与多列工作区；多列只用于真实并行任务 |
| 中等宽度 | 收紧页边距与辅助栏，主工作区保持完整 |
| 窄屏 | 侧栏进入抽屉或紧凑模式，主辅工作区收敛为单列，插件网格按专用断点排列 |
| 手机 | 隐藏面包屑与工作区页签，表格型业务列表使用摘要行，插件保留单列卡片，低频筛选按页面进入抽屉或折叠面板，控件目标提升到触控尺寸 |

响应式变化只调整结构、密度和导航呈现，不使用流式标题字号，也不删除正式功能。代码、长路径和技术字段可以在所属区域局部横向滚动；普通业务页面不得产生页面级横向滚动。

插件网格随视口宽度从单列逐级增加到五列，断点以组件代码为准，内容仍遵循工作区宽度偏好。插件卡片保持统一最小高度，长元数据与健康提示可使卡片自然增高，不固定所有行的高度。2K 桌面以每屏约 10–15 张完整卡片为密度目标，可见数量随内容、视口高度和宽度偏好变化，不保证在所有内容条件下成立。

## 验收条件

- 首次主题跟随系统，显式亮暗选择可持久化，切换后无不可读或缺失状态。
- 主文本、次文本、链接、按钮、控件边界、焦点和语义状态达到 WCAG 2.2 AA，并支持 forced-colors。
- 页面符合 [`DESIGN.md`](../../DESIGN.md) 的 Do's and Don'ts；独立插件集合保留卡片网格，不把该例外扩展为所有数据页的布局。
- 插件卡片状态可读，管理入口和图标操作可通过键盘辨认和触发；历史日志折叠保留筛选与焦点，全局插件设置的草稿反馈和保存入口位于同一稳定区域。
- 管理工作区的表单、列表与日志保持实色；导航、浮层、磁贴与认证面板的玻璃都具有不透明降级，管理工作区选中底色和文字保持中性。
- 认证入口在亮暗、窄屏与低高度视口下保留字段和操作；恢复指引往返保留凭据与焦点，说明中的停服、本机重建和会话失效条件清楚可见。
- 页面使用产品组件，复用现有请求层、WebSocket 封装、Pinia stores 和管理深链 helper。
- `prefers-reduced-motion` 下移除非必要过渡，状态变化仍能立即理解。
