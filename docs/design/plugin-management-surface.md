# RayleaBot Plugin Management Surface

本规范定义插件包内管理页与 Web 宿主工作区的视觉边界。项目级视觉语义以根目录 [`DESIGN.md`](../../DESIGN.md) 为准；插件页面能力、静态资源与同源管理 API 调用以 [`Plugin Management UI`](../plugin/management-ui.md) 与正式 contracts 为准。

## 适用范围

- 宿主遵循雾白·青瓷的颜色、字体、密度、层次、状态和无障碍规范：普通表面、文字、边框与选中背景保持中性，青瓷用于品牌、主操作和少数选中标记。官方插件页面以项目视觉语义为兼容目标，由独立插件仓库维护。
- 第三方插件页面保持实现自治，只需满足宿主边界、主题兼容、键盘操作、对比度和减少动态效果的要求。
- 宿主负责页面标题、页签、可信代码确认、加载、错误、重试和退出工作区。
- 插件页面负责自己的设置、敏感值、状态说明和业务操作，不复制宿主导航或全局页头。

## 技术边界

- 运行期页面只读取插件包内的 HTML、CSS 和 JavaScript 静态产物，不加载宿主组件运行时或全局 store。
- 官方页面由独立插件仓库使用 Vue 3、TypeScript、Vite 和 `@rayleabot/plugin-ui` 构建；组件依赖随页面产物打包，不由宿主提供共享运行时。
- 第三方页面不得假设宿主 CSS custom properties、字体资源或框架组件可用。
- 页面业务交互只使用受保护的管理接口，不增加视觉专用旁路。
- iframe 内部的配色、字体、布局和组件由插件产物维护。

## 主题兼容

- 页面声明 `color-scheme: light dark`，并以同源宿主页面的主题变量为主题来源；读取前可使用 `prefers-color-scheme` 提供无闪烁的初始主题。
- 官方页面在两套主题中映射项目级画布、表面、文本、边界、brand 主操作、暖色人工关注和语义状态；页面实际采用的主题值由 SDK 与插件产物决定。
- 第三方页面可以使用自己的品牌颜色，但文字、控件、焦点和状态必须满足 WCAG 2.2 AA，且颜色不得成为唯一信息。
- 官方页面通过 Vue SDK 将宿主亮暗模式与主题变量映射到页面根节点，不读取宿主应用状态。
- 主题变量集合发生变化时，同步宿主、Vue SDK、官方插件和文档。

## 宿主工作区

- 宿主标题和页签使用 Web 管理面的标准组件与密度。
- iframe 外围使用完整中性边框和项目级表面，不使用彩色侧边条、玻璃材质或多层卡片。
- 宿主菜单与确认浮层沿用 Web 产品浮层的不透明表面；iframe 内容背景、设置表单、列表和日志同样保持不透明。
- 加载状态使用与页面工作区一致的骨架；失败状态说明原因、重试操作和返回插件详情的入口。
- 未验证来源确认使用暖色人工关注语义，危险或失败状态继续使用正式语义色。
- 宿主品牌与标题使用共享折叶标识和自托管 Noto Sans SC；手机上的启停开关与相邻操作使用至少 `44px` 触控目标。
- 宿主标题、设置分组、保存反馈、启停及相邻工具保持紧凑对齐；页面加载、空数据、失败、未保存和保存生效具有可区分的文字状态。
- 插件页面不得在内容内重复宿主标题、插件名称、信任提示或全局导航。
- iframe 内部的配色、字体和页面构图由插件产物持有；宿主不注入样式或将自身字体视为 iframe 已有资源。

## 官方页面布局

- 页面根容器使用项目级画布与表面 token，正文使用系统无衬线字体，日志和标识符使用等宽字体。
- 桌面控件高度 `36px`，窄屏或粗指针目标高度 `44px`。
- 设置页面使用单列或清晰的两列字段布局；字段说明紧邻控件，连续说明最大宽度 `72ch`。
- 列表、订阅项和账号项优先使用数据行与分隔线；只有独立对象或独立操作才使用有边界表面。
- 主操作使用页面自己的 brand 映射，人工确认使用暖色 attention，成功、警告和危险使用独立语义色。
- 页面不得使用同尺寸卡片墙、嵌套卡片、hero 指标模板、渐变文字或装饰性悬停位移。
- 官方游戏插件页面以工作区组织：一个宿主页签对应一个工作区，页面顶部是标题与一句说明，账号相关的工作区在同一行右侧放一个共用的角色选择器；下方是左侧的分区导航（桌面竖排、窄屏改为横向滑动）与内容列，内容列一次只显示一个分区，分区内表单在前、结果紧随其后，上次打开的分区在浏览器会话内记住。分区不各自提供角色选择，只读工作区的选择；列表使用数据行，确认操作内联在对应行内，查询结果这类独立对象才使用有边界表面。

## 交互与无障碍

- 所有正式操作可通过键盘完成，焦点顺序与视觉顺序一致。
- 焦点轮廓与相邻背景至少达到 `3:1`，正文达到 `4.5:1`。
- 错误与保存结果关联到对应字段或操作，并同时提供文字信息。
- `prefers-reduced-motion` 下移除非必要过渡；轮询和任务进度仍提供静态状态文本。
- 窄屏布局保持设置、保存、删除、触发和返回宿主的完整能力。
- 敏感值字段不得在提示、示例、日志或视觉测试数据中包含真实凭据。

## 验收条件

- 官方页面在系统亮暗主题下具有完整、等价且可读的状态与操作。
- 第三方页面不依赖宿主内部 CSS、store 或 token。
- 宿主加载、错误、可信确认和 iframe 边界符合 Web 界面规范。
- 官方页面与宿主工作区符合 [`DESIGN.md`](../../DESIGN.md) 的 Do's and Don'ts；宿主浮层使用不透明表面。
- 视觉规范不改变插件 manifest、静态资源路由、CSP 或管理 API。
