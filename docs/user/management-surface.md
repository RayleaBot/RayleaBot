# Management Surface

本页说明 RayleaBot 当前正式提供的管理入口、页面职责和跨页查看路径。

## 当前正式入口

| 入口 | 作用 |
| --- | --- |
| Web 管理面 | 在线管理主入口 |
| Launcher | 桌面启动、停机、本地预检和打开管理面 |
| CLI | 本地离线恢复与诊断入口 |

常规插件管理、状态查看、日志查询和配置编辑以 Web 管理面为主。服务端是正式状态来源，Launcher 负责桌面壳交互与本地进程编排。

## Web 管理面页面

| 页面 | 路由 | 作用 |
| --- | --- | --- |
| 系统状态 | `/` | 查看健康、就绪、聚合诊断、近期变化、系统工具和正式更新状态 |
| 菜单中心 | `/menu-center` | 查看平台内置菜单、声明指令和当前可用菜单入口 |
| 插件列表 | `/plugins` | 安装、卸载、启用、禁用、重载和查看插件列表 |
| 插件商店 | `/plugins/store` | 浏览商店目录、查看来源与信任信息并进入插件安装确认 |
| 全局插件设置 | `/plugins/settings` | 查看和保存指令前缀与插件图片底部说明 |
| 插件详情 | `/plugins/:id` | 在概览查看运行状况、功能、安装与配置和项目资料，失败时就地重载；另有指令、实时输出和插件内置管理页 |
| 权限策略 | `/permission-policy` | 查看和保存超级管理员和默认权限 |
| 黑白名单 | `/access-lists` | 管理白名单、黑名单和白名单启用状态 |
| 限流中心 | `/rate-limits` | 查看和保存用户指令、群指令、外发消息限流和冷却提示 |
| 指令中心 | `/commands` | 查看当前生效指令策略和全部声明指令 |
| 定时任务 | `/scheduler` | 查看插件声明的定时任务、运行状态与耗时，手动触发并查看执行日志 |
| 实时日志 | `/logs` | 查看当前服务启动窗口内的日志、指令策略拒绝记录和增量更新 |
| 历史日志 | `/logs/history` | 查看按时间范围筛选的历史日志和指令策略拒绝记录 |
| 协议中心 | `/protocols` | 管理已配置连接，通过弹窗新增或编辑连接 |
| 配置 | `/config` | 查看和保存通用配置 |
| 模板预览 | `/render/templates/:templateId?` | 查看模板信息、输入结构和同步 HTML 预览结果 |

## 权限策略页

- `/permission-policy` 提供超级管理员和默认权限级别配置。
- 超级管理员填写 OneBot11 QQ 账号，跨 OneBot 连接生效并跳过黑白名单与冷却拦截；QQ 官方机器人的用户不能通过此列表设为超级管理员。未单独声明权限的指令沿用默认级别。
- 页面仅在内容变化后允许保存，并显示未保存或已生效状态。

## 限流中心页

- `/rate-limits` 集中显示用户指令、群指令和外发消息三类限流，以及命中后的冷却提示开关。
- 每项限流采用“次数、时间窗口、单位”的组合输入，页面同步显示可读预览。
- 冷却提示用于用户指令或群指令命中限流后的提示发送。
- 用户、群与外发目标的限流按协议、连接和机器人身份分别累计，同名目标不会跨连接共享额度。目标消息限流覆盖插件外发消息和平台冷却提示。

## 黑白名单页

- `/access-lists` 使用白名单和黑名单两个连续分区负责名单管理，每个分区显示条目数、筛选和操作；筛选时写明匹配数与总数。某个名单读取失败时，分区内会说明原因并提供重试。
- 白名单和黑名单列表都支持按“全部 / 用户 / 群”筛选、直接查看当前完整列表和单条移除。
- “添加条目”需要选择作用域、类型并填写目标 ID 和原因。OneBot 全局规则作用于所有 OneBot 连接；指定实例的规则还需填写连接标识与机器人 ID。QQ 官方 openid 必须使用实例作用域。
- 删除仅影响所选作用域内的条目，相同目标 ID 在其他实例的规则会保留。升级前的无作用域条目归入 OneBot 全局；旧 QQ 官方规则需要重新绑定实例与机器人。
- 列表中的目标 ID 支持点击复制，复制成功后会显示“已复制目标 ID”反馈。移除条目前的确认会写明名单、对象和适用范围。
- 白名单分区提供服务级启用开关，所有连接均受其约束。名单为空时启用会要求确认；启用后只有命中白名单的指令和 OneBot 超级管理员可通过准入检查，指令自身权限与冷却仍按各自规则执行。
- 白名单已启用且当前为空时，页面会持续显示“白名单已启用且当前为空”风险提示，提醒尽快补充条目或先关闭白名单。

## 页面联动

- 系统状态页的协议提醒和近期变化会提供到协议中心、日志中心和插件详情的入口。
- 系统状态页通过 `GET /api/update/status` 读取正式更新状态，通过 `POST /api/update/check` 触发发布元数据检查；Web 不下载或安装更新，桌面完整包在 Launcher 中一键更新，服务端包停服后执行 `raylea-server update apply`。
- 订阅中心插件详情页提供订阅状态、用户解析和立即检查入口。
- 协议中心首页展示已配置连接和运行状态。“添加连接”在弹窗中选择协议、填写配置，保存时才创建实例；取消不会写入配置。高级设置按需展开，包含连接标识、QQ 沙箱环境或所有连接共用的重连策略。
- `/protocols?adapter={id}` 打开指定连接的配置弹窗。旧的 `/protocols/onebot11/{id}` 和 `/protocols/qqofficial/{id}` 地址会转到对应弹窗。
- 连接弹窗中的运行状态与诊断入口可进入实时日志，自动带上当前协议的筛选。每个实例展示自己的正式运行摘要，OneBot 实例同时展示各自的详细传输快照。
- 权限策略承担超级管理员和默认权限配置；黑白名单承担名单条目和白名单启用状态；限流中心承担指令与外发消息限流及冷却提示配置。
- 插件中心侧栏包含插件列表、插件商店、全局插件设置、菜单中心、指令中心和已安装插件。每个插件都能独立展开概览和 manifest 声明的内置管理页，展开或收起一个插件不会改变其他插件；当前页面对应的插件会自动展开，返回主导航时页面保持不变。
- 插件商店区分三种安装阻碍：无法确认当前 RayleaBot 版本、已知版本低于插件要求，以及没有当前平台的安装包。版本无法确认时，通常是源码构建或安装目录中的 `build_info.json` 缺失、无效；应使用带有效构建信息的发行产物后再安装。已知版本过旧时升级到插件要求的最低版本；缺少平台安装包时需等待发布者提供。普通本地安装与商店安装采用相同的版本要求，已安装插件的更新也受此限制。
- 从侧栏选择插件时进入该插件的概览。
- 插件列表使用卡片网格，筛选工具位于列表上方。插件名称进入概览，“管理”按钮进入插件声明的首个内置管理页；未声明管理页时显示概览。
- 指令中心支持 `plugin_id` 过滤，指令表中的插件列可直接进入插件详情。
- 插件详情提供当前插件的指令中心入口、历史日志入口，以及同一页内的插件管理页工作区切换。
- 实时日志与历史日志支持 `level`、`source`、`protocol`、`plugin_id`、`request_id` 和 `log_id` 工作区 query；`level` 与 `plugin_id` 可重复传入多个值，历史日志额外支持 `start_at` 与 `end_at`。
- 日志页的筛选修改后自动生效，无需点击应用。级别与模块常驻，协议、插件和请求 ID 在窗口放得下时直接显示在筛选栏，放不下的收进“更多筛选”；两个日志路由共享相同的筛选与详情结构。
- 指令被白名单、黑名单、权限或冷却拒绝时，日志中心会显示拒绝摘要，日志详情会显示 `command_name`、`error_code`、`reason`、`policy_stage` 和匹配插件列表。
- 日志详情会根据稳定字段提供插件详情、协议中心和请求 ID 对应日志页入口；异步任务日志使用 `source=tasks`。
- 模板预览页的结果区显示当前模板的同步 HTML 预览结果。
- 模板目录按插件名称分组，优先显示模板名称，可搜索插件、模板名或标识。效果预览、示例数据和模板说明分别展示；修改示例数据只影响当前预览，可恢复默认示例。刷新目录会移除已失效的条目，内部标识和版本放在模板说明中按需查看。

## 插件内置管理页

- 插件在 manifest 中声明 `management_ui.pages` 后，插件中心侧栏会显示对应内置管理页入口；侧栏折叠时，详情页内的切换控件提供相同入口。
- 管理页静态资源从管理面同源路径 `/plugin-ui/{plugin_id}/` 只读提供，响应 CSP 只允许加载该插件 UI 路径下的脚本。
- 插件页面沿用当前登录会话直接调用插件设置、密钥和管理动作接口。
- 密钥界面只显示是否已配置，允许覆盖写入与显式删除，从不读取或回显已有明文。
- 未验证来源插件首次打开内置管理页时需要手动确认；插件版本或来源变化后会重新确认。
- 插件管理页读取和保存插件设置；插件管理动作通过 `POST /api/plugins/{plugin_id}/management/actions` 转给插件 runtime 处理。
- 插件安装前，操作者必须明确确认插件后端会作为完全可信的本地代码运行；从商店安装时，确认框同时列出版本与需要确认的原因。目标平台、artifact 与资源上限由服务端安装校验，不符合时安装失败。

## 配置工作台

`/config` 按六个分类组织通用配置。先选择分类，再调整常用参数；浏览器、队列、会话等高级参数在当前分类内展开。搜索框可以按配置名称、说明或字段路径查找，包括折叠区内的参数。默认值显示为输入框为空时的占位文本（placeholder）；它仅提供提示，不会自动填入或提交。

各分类共用一份草稿，切换分类与搜索不会丢失输入；尚未填完整的限流参数也会保留，保存前需补齐。右下方的保存浮标在未修改时保持中性，有修改时变为人工关注色（紫色）并显示未保存项数，点击可一次提交所有分类的修改。保存浮标左侧的“撤销修改”按钮恢复最近收到的配置。离开页面前可以选择继续编辑或放弃修改。保存期间显示加载图标，失败时草稿保留并提示重试，成功后恢复中性；悬停或聚焦浮标可查看状态，需要重启才能生效的结果也会通过保存通知说明。

## 状态来源与 Launcher 管理入口

- Web 与 Launcher 都直接访问服务端管理接口。
- Web 使用正式 HTTP API 与管理 WebSocket 读取状态和提交操作。
- Launcher 使用 `healthz`、`readyz`、`/api/setup/status` 和 `/api/launcher/status` 检查本机服务连接，并把这些正式结果与本地进程状态一起展示。
- Launcher 打开 Web 时只打开管理面 URL；Web 管理面通过初始化和登录接口建立会话。
- 未登录状态打开 Web 深链时进入登录页；登录或初始化完成后返回目标页面。
- Launcher 停止本机服务使用 `/api/launcher/shutdown`。连接非本机服务时，Launcher 只做连接检查和打开 Web。

## 本地优先安全边界

- 管理入口默认监听 `0.0.0.0`，支持本机与局域网访问；网络访问控制由用户负责。
- Web API 和 WebSocket 都要求正式管理会话。
- Web 状态变更请求使用 HttpOnly cookie 会话，并校验 Origin 与 CSRF；本机 Launcher 控制接口另用 loopback 限制和 control token。
- 登录失败次数受限，避免暴力猜解管理员凭据。
- 第三方插件不具备管理权限，插件能力与管理权限保持隔离。

## 初始化与会话

已登录时，左下角“账号 → 修改账号”可修改管理员密码。输入当前密码、新密码与确认密码；需要修改用户名时展开“同时修改用户名”，留空则保留原用户名。新密码为 8–1024 个字符，前后空格会保留。保存成功后，所有设备的旧会话失效，使用新凭据重新登录。错误密码不会改动账户，验证尝试与登录共用失败次数限制。

- 首次启动没有管理员账户时，服务进入 `setup_required`，开放需一次性 token 的初始化路径。
- 初始化完成前，不开放常规插件管理、配置修改和日志查询。
- 忘记管理员密码时，正式恢复路径是通过 Launcher 的“重置管理员账号”或停服后的 CLI 触发 `reset-admin`。
- 管理会话采用有限 TTL，可做滑动续期，但保留绝对有效期上限。
- 重置管理员账号后，旧会话全部失效。
- 未登录访问受保护页面时，管理面进入初始化页或登录页，并在完成后回到目标页面。

## Launcher

- full artifact 统一以 Launcher 作为桌面入口。
- Launcher 负责启动、停止、重启服务、本地预检、打开管理面和版本提示。
- Launcher 本地预检关注安装根、`raylea-server` 路径、`config/user.yaml`、工作目录和启动器设置。
- 模板、浏览器和原生插件进程异常通过服务端 readiness 与系统 diagnostics 暴露；Launcher 组合这些正式结果和本地 preflight 展示启动状态。
- 启动时若本机已存在健康服务但不属于当前 Launcher 子进程，界面会标示“检测到现有服务”。
- 启动失败摘要来自健康探测、stderr 和日志尾部。
- 关闭窗口默认询问处理方式；隐藏到托盘时服务继续运行。
- 用户选择完全退出时，Launcher 停止由它启动的服务；其他程序启动的服务不受影响，需要时在 Web 管理面停止。
- Launcher 打开 Web 管理面时只打开普通 URL，管理会话由 Web 初始化和登录流程建立。

## 入口职责矩阵

| 场景 | Web 管理面 | Launcher | CLI |
| --- | --- | --- | --- |
| 在线状态查看 | 主入口 | 桌面壳视图 | 否 |
| 在线插件管理 | 主入口 | 打开 Web | 否 |
| 首次初始化 | 主入口 | 打开 Web | 否 |
| 凭据丢失恢复 | 否 | 可触发本机恢复入口 | 主入口 |

| 停服恢复与迁移 | 否 | 否 | 主入口 |
